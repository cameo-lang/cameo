# ex1: a Go program that embeds cameo

The smallest program that does the three things an embedding is for: it
defines a class in Go, runs a script that uses the class, and calls a
method the script defines.

```sh
go run ./examples/ex1                # runs hello.cameo, which is built in
go run ./examples/ex1 mine.cameo     # runs a script of your own
```

```
Hello, world!
HELLO, cameo!
Hello, again!
from Go: Welcome, Go!
```

| File | Holds |
|---|---|
| [greet.proto](greet.proto) | the message behind the class: one field, `greeting` |
| [greetpb/greet.pb.go](greetpb/greet.pb.go) | its Go code, generated by `make proto` and committed |
| [main.go](main.go) | registers the class `Greeter` with two methods in Go, loads the script, runs it, calls `welcome` |
| [hello.cameo](hello.cameo) | the script |

`Greeter.new(greeting: "Hello")` in the script is a `*greetpb.Greeter` in
Go. A method gets a copy of the instance it is called on, so `louder`
returns a new `Greeter` and the script's `greeter` stays as it was: cameo
values are immutable, also across the border to Go.

To try it on a script of your own, write one that uses `Greeter`:

```ruby
names = %w[Ada Grace Barbara]
hi = Greeter.new(greeting: "Hi")
names.each { |name| puts hi.greet(name) }
```

The site's [Embedding in Go](https://cameo-lang.github.io/cameo/go.html)
and [Native code](https://cameo-lang.github.io/cameo/native.html) pages
have the rest: values both ways, errors, modules of Go functions, workers.
