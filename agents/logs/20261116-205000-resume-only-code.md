**Started:** 2026-11-16 20:50:00

## Objective
Give `cameo.Resume` an option that limits the code a resumed program takes
from a dump, checked where cameo takes a unit, so a host does not have to
walk the dump, which misses a closure inside an object's fields.

## Obstacles
- **Issue:** A dump puts a closure's unit in its list of units, not in the
  closure, so swapping in another dump's object was refused for a missing
  unit, not for other code.
  **Resolution:** The test moves the unit into the closure inside the
  object's encoded fields, through the class's descriptor, and checks that
  the crafted dump runs the other code without the option.

- **Issue:** The local checkout of cameo was 191 commits behind, so the
  guidance first read said to push review fixes as new commits; main's
  says a pull request is one commit.
  **Resolution:** The review fixes are amended into the one commit.
