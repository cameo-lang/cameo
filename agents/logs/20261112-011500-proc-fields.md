# Task: a class with a proc field is a message

**Started:** 2026-11-12 00:50:00
**Ended:** 2026-11-12 01:15:00
**Strategy:** Feature (TDD)
**Status:** Completed
**Complexity:** Simple
**Used Models:** Fable 5.2
**Token usage (Estimated):** 300k input, 20k output

## Objective
Step 28 of `doc/design/ir.md`: the last of the four rules a Proc had
because it could not be serialised. A class with a proc field is a
message, and its instances cross the envelope, `async`, a Go host and a
dump with their blocks.

## Progress
- [x] The instance conversion takes the encoder or the decoder it is
      part of, which has the codec for procs
- [x] A proc field is a `cameo.Closure` in the descriptor and in the
      `.proto` text, whose file imports the envelope's
- [x] `to_proto`, `from_proto` and the host's conversion use an encoder
      with procs
- [x] An exception's parts and fields are encoded by the encoder the
      exception goes through
- [x] Tests: the message, the envelope, `async`, a dump, a Go host,
      `cameo proto`, and a reader that is another program

## Obstacles
- **Issue:** The first closure of a unit carries the code, and a protobuf
  map has no order: a reader without the code met a closure that named
  the unit before the one that carried it.
  **Resolution:** The closures of a map field are written and read in the
  order of their keys.
- **Issue:** A subclass's instance in a field of its parent was written
  whole and then re-read as the parent's message. A proc field of the
  subclass was encoded, marked its unit as sent, and was read by nobody.
  **Resolution:** Such an instance is written from the parent's fields
  alone.
- **Issue:** An instance kept its message once built. A closure is made
  for one reader: with the code or without, in a dump with a frame.
  **Resolution:** An instance of a class that holds a proc does not keep
  its message.

## Outcome
`Route.proto` shows `optional cameo.Closure handler`, and a Route goes
wherever a value goes. An exception in a dump now tells the dump the
classes of the values its parts hold, which it did not before.
