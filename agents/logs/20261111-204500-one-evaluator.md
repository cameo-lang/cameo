# Task: run every program on the IR, and remove the tree walker

**Started:** 2026-11-11 20:45:00
**Ended:** 2026-11-11 21:40:00
**Strategy:** Refactoring
**Status:** Completed
**Complexity:** Simple
**Used Models:** Fable 5.2
**Token usage (Estimated):** 450k input, 40k output

## Objective
Step 10 of `doc/design/ir.md`: with every form compiling, make the IR
evaluator the only one, compile a program into one unit, and delete the
tree walker.

## Progress
- [x] ruby/spec's language and core on both evaluators before the removal:
      3,938 rows of status, none different
- [x] A program is one unit, compiled before it runs: the script, a
      library written in cameo, a console line, a debugger expression
- [x] `POP`, so that a `DROP` in a body is the end of a statement of the
      source and the top level splits into its statements
- [x] The tree walker's functions, `Proc.Block`, the AST parameter lists,
      the per-method compile cache, `TreeWalkerOnly` and `IRCounts` removed
- [x] `make check`, the conformance run and ruby/spec again on the result

## Obstacles
- **Issue:** The converter rewrites one construct into a sequence of
  expressions (`syntax.Seq`), which compiled inline with `DROP` between
  them. Splitting the top level at its `DROP`s then gave more statements
  than the source has, and the pause point is an index of a statement of
  the source.
  **Resolution:** A sequence is separated by `POP`. `DROP` ends a
  statement of a body, and nothing else.
- **Issue:** `specs/run.rb` needs a UTF-8 locale, as the conformance run
  does, and 22 rows of its status differed between two runs of the same
  binary.
  **Resolution:** `LC_ALL=C.UTF-8`. The 22 rows carry an error message of
  protobuf-go, which varies the whitespace in its messages on purpose;
  the status columns are equal.
- **Issue:** Removing some twenty functions by exact-text edits would
  have cost more than the functions.
  **Resolution:** A forty-line Go program in the scratch directory removes
  top-level declarations by name, through go/parser.

## Outcome
One evaluator. `src/eval` no longer evaluates an AST node; the AST is the
compiler's input and `cameo build`'s. Next is a frame that names its
method and classes instead of pointing at them, and then the closure in
the envelope.

## Insights
Running ruby/spec on both evaluators was the check that made the removal
safe: the Go tests and the examples had passed on both for three pull
requests, but ruby/spec has thirty times the examples. It should have run
with the first slice, not only before the removal.
