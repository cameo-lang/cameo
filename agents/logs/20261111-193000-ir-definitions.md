## Obstacles
- **Issue:** `examples/base64.cameo` did not marshal: a protobuf string
  is UTF-8, and the script has a string literal with other bytes.
  **Resolution:** A literal that is not valid UTF-8 is a bytes constant,
  which CONST reads as a String. A symbol or a name with such bytes still
  does not marshal; none of the corpus has one.
- **Issue:** The tree walker checks where a declaration stands (a field in
  a class body, an include in a body or at the top level) before it
  evaluates the declaration's operands; the IR has evaluated them when the
  instruction runs.
  **Resolution:** The checks are functions of their own, called by the
  tree walker first and by the shared function again. The IR raises the
  same error, after the operands ran.
- **Issue:** Tests that used a `class` or a `begin` as the form that does
  not compile yet lost their case slice by slice.
  **Resolution:** The one node without an instruction is a splat outside
  a list, which only a tree built by hand has; the test builds one.

## Outcome
The compiler covers the language. The tree walker still runs when
`eval.TreeWalkerOnly` is set, and for nothing else the corpus has.

## Insights
Splitting each `evalX(node, env, fr)` into "evaluate the operands" and
"do it with values" was mechanical, and gave the IR evaluator its
semantics without a second implementation, patterns excepted.
