## Objective
The classes step of doc/design/aot.md: methods of top-level classes with
typed fields compile, with field reads as typed loads, parameters typed by
the fields read on them, and direct calls on instances of known classes.
Construction stays with the interpreter for now.

## Obstacles
- **Issue:** The generator's resolution of a bare call used the checker's current method, which was whatever the last round checked, and dereferenced nil.
  **Resolution:** Resolution takes the owning class as an argument from both.
- **Issue:** The compiled Mandelbrot count on fields was one point off the interpreter's. Go fused `scale * y + top` into one instruction with one rounding on arm64; the interpreter rounds each operation.
  **Resolution:** Every Float operation is written as `float64(a op b)`, an explicit conversion, which the Go specification says prevents fusion. The plain-Float count of 04-floats agreed by luck.
- **Issue:** join(unknown, never) returned never, so a method returning through itself alone typed as nothing; the Floats step passed its test by accident.
  **Resolution:** never yields to anything first, unknown second.
- **Issue:** Ruby cannot run scripts with cameo's field declarations, and a prelude defining them as attr_accessor is rejected by cameo.
  **Resolution:** run.rb gives a Ruby that fails "-" cells and prints the error once; the README compares the field-based Mandelbrot with the local-based one of 04-floats instead.

## Outcome
Class methods compile: mandelbrot on fields 0.022 s compiled against
2.839 s interpreted; pairs through ref fields 0.110 s against 10.050 s.

## Insights
A conformance difference of one grid point in ten thousand found the FMA
