## Objective
`cameo irb [script]` evaluates lines typed in at the top level of a
script, prints each value, and waits for the rest of an expression that
is not whole yet. With a script given, the script runs first and the
lines see what it defined.

## Progress

- [x] tests: Go tests through the host API and the command, one

## Obstacles
- **Issue:** The parser reads a bare name as a method call unless it saw
  the name assigned earlier in the same parse, so `inc(x)` typed after
  `x = 41` called a method x.
  **Resolution:** A snippet is parsed behind `x = nil if false;` for each
  variable bound at the top level, an assignment that never runs. `x = x`
  did not work: this parser resolves the right side before it binds the
  left.

## Outcome

## Insights
Incomplete input is a parse error that names "(EOF)"; irb reads on
when it sees one, as Ruby's irb does.
