## Objective
Abstract the host's I/O behind an interface, cameo.Env: it loads script
files and gives the streams and the files a script reads and writes.
cameo.Load, a new cameo.LoadFile, Run, RunFile and Resume take one. The
default, the machine's own files and standard streams, lives in a
package of its own, so that an integrator can show they do not use
cameo's default I/O.

## Decisions (from the owner)
- Everything goes through the Env: the file system scripts read and
  write too, and Run and Resume take an Env. Program.FileSystem and
  Program.AllowHostIO go.
- The default is a separate package. It is cameoio, not cameo/io: a
  package named io clashes with Go's own in nearly every file.

## Insights
- cameoio satisfies cameo.Env by its method set alone, so it needs no
  import of cameo and cameo's tests can use it without a cycle.
- Package cameo still reaches the host in three places outside the Env:
  File.expand_path reads HOME and the working directory, Logger prints
  the process id, and time zones read the system's zoneinfo.
