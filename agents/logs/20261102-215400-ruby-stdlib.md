# Task: Ruby's standard library in cameo — proposal, layout, and the first libraries

**Started:** 2026-11-02 21:54:00
**Ended:** in progress
**Strategy:** Feature (TDD)
**Status:** In Progress
**Complexity:** Medium
**Used Models:** Fable
**Token usage (Estimated):** 400k input, 60k output

## Objective
Decide which of Ruby 3.4's libraries cameo builds in, which it leaves out
and why, write it down with a status per library, and build the first ones:
`uri`, `date`, `net/http`, time zones. One pull request per library, and
one Go package per library under `src/lib/<require path>`, which means
moving `json`, `cgi`, `benchmark`, `time` and `pathname` out of `src/stdlib`
first.

## Obstacles
- **Issue:** eval dispatched `inspect`, `to_s` and `==` only to a class's
  user-defined methods, and `Benchmark::Tms` had special cases in
  inspect.go; a library class could not render or compare its instances.
  **Resolution:** `ownNative` in eval/inspect.go: a native method of a
  class other than Object and BasicObject (not a module's) is a class's
  own, and the fallbacks stand aside. The same hook lets `u.port = "x"`
  reach a native `port=` setter, which checks the value and returns the
  copy.
- **Issue:** `DateTime.strptime("1709164800", "%s")` gave today: the
  fragment completion took the time-only table (hour, min, sec present)
  and set the day to today over the one the seconds had set.
  **Resolution:** the day is filled only when absent, as Ruby's
  rt_complete_frags does.
- **Issue:** Ruby's RFC 3986 `seg` includes the slash; a first port of the
  grammar without it parsed only one-segment paths.
  **Resolution:** the probe against CRuby 3.4 found it on its first line.
- **Issue:** The `ruby` on PATH is 3.3.6 (uri 0.13.1, date 3.3.4); the
  libraries follow Ruby 3.4.1 (uri 1.0.2, date 3.4.1).
  **Resolution:** `benchmarks/warmruby` runs CRuby 3.4.1 on wazero in
  under two seconds; expected outputs come from it. `net/http` does not
  load there (no sockets in WASI), so its behaviour is checked against
  Ruby 3.3.6's net-http 0.4.1 and the 0.6.0 source.
