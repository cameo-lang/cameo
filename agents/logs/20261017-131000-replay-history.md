**Token usage (Estimated):** 1.2M input, 250k output

## Objective
Bring amber's history from radiospiel/ark (`parts/golang/amber`) into this
repository as one pull request per step, in ark's order, each with a
document in `doc/history/` on what the step did and why, and a second pull
request that points the document's code references at the commit the step
merged as. Three decisions ark took late apply from their first step: Ruby's
class names `Array` and `Hash`, regular expressions on Go's regexp, and
strings that carry their encoding without a `Bytes` class. No optimisation
lands earlier than it did in ark.

- [x] All 36 steps build and pass `make check` before any was pushed.

## Obstacles
- **Issue:** ark's milestone-0 command lived in `src/amber`, where this
  repository's host API package is.
  **Resolution:** the builder moves it to `src/cmd/amber` and fixes the
  examples path.
- **Issue:** the warm WASM CRuby command links ark's AGPL agentic module.
  **Resolution:** left out; `compare.rb` runs the other three Rubies and
  checks against MRI, and the results measured in ark with all four stay.
- **Issue:** a fuzzy `patch` misplaced hunks when reordering paths before
  encodings.
  **Resolution:** applied strictly, resolved the four rejects by hand, and
  kept the result as a patch for the builder.
- **Issue:** several drafted claims did not hold when checked (a setter
  message, an anonymous class's inspect, an int field's error class, a DOI).
  **Resolution:** each was run on the step's binary or looked up, and
  corrected before the pull request.

## Outcome
`main` holds the 36 steps; its source, examples and benchmark corpus match
ark's final amber, apart from the version command and one comment that
names `Array` and `Hash`. `doc/history/README.md` indexes the documents.
Open, as the documents say: `sort` of integers is 19 times MRI's, and
ruby/spec has not been run.

- Measuring each optimisation on the replayed binaries gave every
