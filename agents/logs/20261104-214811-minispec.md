## Objective
examples/frankie, a Sinatra-like web DSL on a Go host, needs a way to
write its specs in cameo. No test library exists: the ruby/spec prelude is
a harness tied to run.rb's rewrite, and doc/stdlib.md rules minitest out and
asks for "a test helper of cameo's own". Build minispec, `require
"minispec"`: `describe`, `it`, `skip` and minitest's `assert_*` and
`refute_*` functions (the human chose assert functions over expectations),
with minitest's report at the end of the script. The report needs an
end-of-script hook, so `at_exit` comes first, as its own pull request.

## Obstacles

- **Issue:** a block given to a host method (`Module.Def`) is dropped, so a Sinatra `get "/x" do … end` cannot reach Go as a block.
  **Resolution:** the host API is given the block, as Ruby's C API gives every method its block: Func and Method take a *cameo.Block, and a Proc argument arrives as one.
