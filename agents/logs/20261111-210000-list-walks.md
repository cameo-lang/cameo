# Task: the walks of a List as steppers

## Objective
Step 23 of `doc/design/ir.md`, its first group: the builtins a script
walks a list with become steppers, so a run pauses inside their block.

## Progress
- [x] `stdlib/walk.go`: a walk over elements as one stepper, with what to
      yield, how to fold the block's value and the value at the end
- [x] `List#each` and `each_index`; Enumerable's `each_with_index`,
      `each_with_object`, `map`/`collect`, `flat_map`/`collect_concat`,
      `filter_map`, `select`/`filter`/`find_all`, `reject`, `partition`,
      `find`/`detect`
- [x] `installUserEnumerable` keeps a method a stepper when it wraps it
- [x] A break out of a block a step called from Go ends the builtin
- [x] Tests: every `Test.pause` inside these blocks is a pause of its
      own; paused and resumed output equals one run's

## Obstacles
- **Issue:** `map` and `select` were steppers in `installEnumerable` and
  plain builtins by the time a script ran: `installUserEnumerable` wraps
  every method of Enumerable for a script's own objects, and the wrapper
  had no step.
  **Resolution:** The wrapper keeps the step for the receivers Go
  defines, and runs the method to its end in one step on a script's
  object.
- **Issue:** The test that compares a paused and resumed run with one
  run passed while `map` was no stepper: a pause held off until the
  builtin returns computes the same.
  **Resolution:** `everyPauseLands` counts: a script pauses once for
  every call of `Test.pause`, which fails when a builtin holds pauses
  off. It showed that a Set has a `map` and a `select` of its own.
- **Issue:** Keeping what a walk gathered as a List value, or copying
  the state each step, makes `map` quadratic.
  **Resolution:** The state is one slice: the elements, the index, then
  what was gathered, which `fold` appends to in place.

## Outcome
A pause inside `list.each { … }`, `list.map { … }` and the others lands
at once. Hash and Set have walks of their own, and `inject`, `sum`, the
`_by` methods, `each_slice` and the rest of Enumerable are next.
