# Task: a run goes on when it cannot be dumped

**Started:** 2026-11-11 20:05:00
**Ended:** 2026-11-11 20:30:00
**Strategy:** Bug Fix
**Status:** Completed
**Complexity:** Simple
**Used Models:** Fable 5.2
**Token usage (Estimated):** 120k input, 8k output

## Objective
A script that paused inside a block which holds a StringIO has no dump:
the block cannot travel, and the builtin that calls it cannot go on
without it. `cameo` printed the reason and exited with status 1, and the
run, which `^C` was meant to keep, was gone.

## Progress

## Outcome
`^C` on a script that cannot be dumped where it is costs a message. The
run ends as if it had not been interrupted.
