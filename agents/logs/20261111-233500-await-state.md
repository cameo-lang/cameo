# Task: an await is a state of its activation

**Started:** 2026-11-11 23:10:00
**Ended:** 2026-11-11 23:35:00
**Strategy:** Feature (TDD)
**Status:** Completed
**Complexity:** Simple
**Used Models:** Fable 5.2
**Token usage (Estimated):** 350k input, 20k output

## Objective
The first part of step 25 of `doc/design/ir.md`: a script that waits in
an `await` pauses there, the dump holds what it waits for, and a promise
made by hand that nothing settled is in the dump as pending.

## Progress
- [x] The design of step 25 in `doc/design/ir.md`, "Workers and await at
      a pause": waiting as state, park then freeze, what the dump holds
- [x] `eval/await.go`: `awaiting`, `machine.await` and `awaited`; the
      three await instructions say what the activation waits for
- [x] `pauser`: the run's pause is shared with its workers and wakes a
      waiter that can pause
- [x] `Dump.Activation.awaiting`, `Dump.Promise.pending`
- [x] `Program.PendingPromise(id)` for a host to settle a promise a
      resumed run brought back
- [x] Tests: a pending promise through a dump; a pause while a method
      awaits a list of promises, with one result in and two to come; a
      run that goes on waiting when it is run again

## Obstacles
- **Issue:** An `await` of a list raises its first failure only when
  every promise has settled, and an activation that pauses in the middle
  has some results and some to come.
  **Resolution:** What an activation awaits keeps the index of the
  promise it waits for, the results so far and the first failure.
- **Issue:** No test can see that a script is blocked in its `await`
  before it asks for the pause.
  **Resolution:** The scripts wait for a promise only the host settles,
  so they cannot get past the `await`; the test waits for the line the
  script prints before it, then a fifth of a second, and checks in the
  dump that the activation awaits.

## Outcome
A pause no longer waits for a script that waits. The workers still run
their calls to the end before the dump is written; parking and freezing
them is the second part of the step.
