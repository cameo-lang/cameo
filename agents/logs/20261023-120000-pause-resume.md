# Task: pause a running script on ^C, dump its state, resume and inspect it

**Started:** 2026-10-23 12:00:00
**Ended:** 2026-10-23 13:10:00
**Strategy:** Feature (TDD)
**Status:** Completed
**Complexity:** Simple
**Used Models:** Opus
**Token usage (Estimated):** 150k input, 40k output

## Objective
`cameo script.cameo` pauses on ^C and writes the interpreter's state to a
temporary file as a protobuf message; `cameo resume <dump>` continues the
script, `cameo inspect <dump>` shows what it holds; `--no-pause` keeps ^C
killing the script.

## Progress
- [x] Read the interpreter: a closure-compiled tree walker whose Go stack
      is the continuation, so a pause can only land between top-level
      statements.
- [x] protogen: the Dump message and its codec
- [x] eval: Pause, Dump, Resume on the interpreter
- [x] cameo: Pause, Dump, Resume, InspectDump on Program
- [x] cmd: ^C handling, --no-pause, resume, inspect
- [x] tests: Go tests through the host API, integration test with kill -INT
- [x] docs: README, doc/design/pause.md
- [x] make check, pull request

## Obstacles
- **Issue:** The evaluator keeps a running statement's state on the Go
  stack, which cannot be serialised.
  **Resolution:** A pause lands before the next top-level statement; a
  second ^C ends the script. Documented as the limit of the feature.

- **Issue:** In the integration test, a background job of a bash script
  without job control inherits SIGINT ignored, so `--no-pause` looked as
  if it did not end the script.
  **Resolution:** The test starts the script under `set -m`.

## Outcome
`^C` pauses a script before its next top-level statement and writes a
`cameo.Dump` protobuf message to a temporary file; `cameo resume` and
`cameo inspect` read it; `--no-pause` keeps the old behaviour. `make check`
green: Go tests and 18 integration tests.

## Insights
A closure-compiled evaluator cannot pause inside a statement; the pause
point between top-level statements is the honest limit, and the design doc
says so. A resumed run gets its classes by running the script's definitions
again rather than from the dump.
