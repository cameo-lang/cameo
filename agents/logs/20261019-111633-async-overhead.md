# Task: cut the per-call cost of async

## Objective
A recursive Fibonacci that fans out with `async` (fib(26), about 393,000
calls) runs ten times slower than the sequential one on ten cores. Cut the
cost of one `async` call without changing what a script sees.

## Baseline (10 cores, best of 3)
- fib(26) async: 1.15 s wall, 9.07 s CPU, 1.07 GB peak RSS
- fib(26) sync: 0.10 s wall
- One core: 2.88 s; four cores (0.97 s) beat ten.

Profile: allocation is 70% of single-core time. The protobuf round trip of
the receiver and the arguments costs about 1.0 s of 2.77 s, building a
worker interpreter 0.21 s, the promise table 0.19 s. On ten cores another
3 s of CPU goes to lock contention: the promise table's mutex and the
`select` on the run's stop channel, which every waiting worker queues on.

## Progress
- [x] Workers share one snapshot of the top level until it changes:
  1.15 s to 0.94 s wall, 9.07 s to 7.28 s CPU
- [x] Values that read back unchanged cross without the protobuf round
  trip: 0.94 s to 0.58 s wall, 7.28 s to 3.26 s CPU
- [x] Sharded promise table, sharded stop channels, settled fast path in
  wait: 0.58 s to 0.29 s wall, 3.26 s to 2.23 s CPU
- [x] make check, pull request

## Obstacles
- **Issue:** The first fast path for arguments took a field-less instance of
  a builtin class (`Object.new`) as is, where the envelope rejects it.
  **Resolution:** Only classes the script defined qualify; a test covers
  `Object.new`.
- **Issue:** The test expected a field-less instance to print as `#<Echo>`;
  cameo prints `Echo()`.
  **Resolution:** Corrected the expectation.
- **Issue:** Checking that the new RunContext case can fail (Stop closing one
  channel) hangs the test instead of failing it.
  **Resolution:** Stopped it by hand; the hang is the evidence.

## Outcome
fib(26) with async on ten cores: 0.27 s wall, 1.94 s CPU, 0.52 GB peak RSS
(from 1.15 s, 9.07 s, 1.07 GB); Progress records 0.29 s and 2.23 s for
the same code, from another run. One core: 0.98 s (from 2.88 s). The
sequential version takes 0.11 s, so a fine-grained async still costs more
than it gains; the rest is a goroutine and a worker per call, and the stacks
of about 45,000 parked goroutines.

Follow-up: `Cameo.freeze!` with a content id for the top level, so runners
outside the process can load it by id.
