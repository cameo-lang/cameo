# Task: an Enumerator travels as the call that made it

**Started:** 2026-11-12 01:20:00
**Ended:** 2026-11-12 02:15:00
**Strategy:** Feature (TDD)
**Status:** Completed
**Complexity:** Simple
**Used Models:** Fable 5.2
**Token usage (Estimated):** 400k input, 30k output

## Objective
Step 24 of `doc/design/ir.md`. The plan said "enumerators as step
functions", so that an external enumerator's position survives a pause.
cameo has no external iteration, so there is no position; what was
missing is that an Enumerator could not be serialised at all.

## Progress
- [x] `object.Enumerator.Make` and `Block`: the call that makes the
      enumerator again, recorded where the standard library makes one
- [x] `cameo.Enumerator` in the envelope; the decoder makes the call
      through `protogen.EnumeratorMaker`
- [x] The call a message may name: `object.MakesEnumerator`
- [x] `each` with a block on an enumerator runs the method that made it
      as an activation, where that method is a step function or a
      script's
- [x] Tests: every method of the core that returns an enumerator, the
      envelope, `async`, a dump, what a message may not make a reader
      run, pauses inside `each`

## Obstacles
- **Issue:** Making the call again means the reader calls a method a
  message names. A message could name `send`, or `map` with a block.
  **Resolution:** A fixed list of the builtins that make an enumerator,
  with the cases where one of them computes instead: `index` with an
  argument, `%` on anything but a Range, `lazy` of a script's object, any
  block on a receiver that is not lazy. The method must be one Go
  implements. A method outside the list makes an enumerator that does
  not travel, which is the safe way to be wrong.
- **Issue:** The list is by name, and a method added later is not on it.
  **Resolution:** A test walks every method of the core's values, calls
  it with zero, one and two arguments, and fails for an enumerator that
  does not read back equal.
- **Issue:** That walk found a crash: a lazy `grep` without a pattern
  panicked in Go when it was enumerated.
  **Resolution:** It is an ArgumentError when called.
- **Issue:** Nine tests used an Enumerator as the value no dump carries.
  **Resolution:** They use a Random, or a StringScanner for the handle
  without a hook.
- **Issue:** I made a temporary test file with a shell heredoc, against
  the instruction to edit with the edit tools.
  **Resolution:** Removed; the next probe was written with the Write
  tool.

## Outcome
An Enumerator goes through `to_value_proto`, `async` and a dump, lazy
chains with their blocks. A pause lands inside `e.each { }` for an
enumerator of a builtin that is a step function. Enumerators a library
makes (StringIO, CSV, Matrix, Prime, Date) record no call and do not
travel; an enumerator over the `each` of a script's object lists its
elements in a nested loop, which holds a pause off as the direct call
does.
