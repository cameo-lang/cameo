## Objective
Step 16 of `doc/design/ir.md`: a dump carries the classes, modules,
constants and methods of the run as data, with the units of code they
refer to and an IR version, and `Resume` runs no definition again.

## Obstacles
- **Issue:** The first design referred to a class by its qualified name.
  A `class` statement on a class that is there makes a copy and binds the
  copy, so a subclass defined before keeps a superclass no name leads to,
  and a class nested in a reopened module has a lexical parent no name
  leads to. Two classes of one name are then in the run.
  **Resolution:** A class of the dump has an id: its qualified name when
  the name is bound to it, the name with its digest otherwise. The dump
  carries every class something of it refers to, found from the constants
  on, and the constant tables are restored as tables, apart from the
  classes.
- **Issue:** A library written in cameo adds to a module Go defined on a
  copy of the module, which holds methods and constants only Go has.
  **Resolution:** Such a class has a digest that starts with `+`. The
  dump lists what it has beyond the module Go defined, and the restore
  starts from a new copy of that module.
- **Issue:** `alias old_to_s to_s` followed by `def to_s` is common, and
  the method the alias holds is Go's, with no code to carry.
  **Resolution:** `alias` records the name the method has in its owner,
  and the restore copies that method from the owner's own table, after
  every method with code is back.
- **Issue:** `Singleton` gives a class methods when it is included, and
  keeps the instance on the class, where only Go sees it.
  **Resolution:** The restore runs a module's include hook again. The
  instance is not back; step 26, the save and restore hook for a
  library's state, is where it belongs.

## Outcome
A resumed run has its classes from the dump: a class body that prints
does not print again, and a method an `if` defined is there. An instance
of a class that was reopened after the instance was made still keeps a
dump from resuming, as before; the dump now has what it takes to lift
that, which is the next pull request.
