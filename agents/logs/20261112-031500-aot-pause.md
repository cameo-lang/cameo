# Task: a compiled method leaves its call at a pause

**Started:** 2026-11-12 02:35:00
**Ended:** 2026-11-12 03:15:00
**Strategy:** Feature (TDD)
**Status:** Completed
**Complexity:** Simple
**Used Models:** Fable 5.2
**Token usage (Estimated):** 200k input, 12k output

## Objective
Step 29 of `doc/design/ir.md`. A method `cameo build` compiled runs as
Go, where no pause could land: a compiled loop that never ends never
paused, and a long compiled computation paused when it was over.

## Progress
- [x] One flag for a stop and a pause (`stopper.interrupt`), which the
      pauser sets and takes back; `eval.InterruptFlag`, `eval.Interrupted`
- [x] The generator writes the check with `eval.Interrupted`; the
      examples are generated again
- [x] `machine.call` makes the body of a method that left for a pause an
      activation
- [x] Example `relay.rb`; tests for a pause in an endless compiled loop
      and for a pause and a resume across compiled methods that call
      each other

## Obstacles
- **Issue:** A second flag for the pause would cost every call and loop
  pass of compiled code a second load.
  **Resolution:** One flag, set for either; the slow path asks which.
- **Issue:** Packages generated before read `eval.StopFlag` and return
  `ErrStopped` when it is set.
  **Resolution:** `StopFlag` stays the stop alone. New code reads
  `InterruptFlag`. An old package still stops, and holds a pause off as
  before.
- **Issue:** `examples/aot/floats.rb` does not build: a block in it sets
  a variable of the scope around it. It is not in the list the test
  reads, so nothing noticed.
  **Resolution:** Left as it is; reported.
- **Issue:** I ran `relay.rb` on the interpreter to get its output, which
  took 90 seconds.
  **Resolution:** The test computes the number in Go, and the example
  has no `.expected`, so the test that runs every example on the
  interpreter skips it.

## Outcome
A pause lands in compiled code at its next call or loop pass. The dump
holds the call the interpreter made as an activation at its start, and
the resumed run calls the compiled methods again.
