## Objective
Give agents a short, agent-oriented documentation of cameo that a tool
can print and a program can hand to its models: markdown topics embedded
in a Go package, `cameo agent-docs [topic]` to print them, so that a
project such as ark can tell its agents "run cameo agent-docs".
