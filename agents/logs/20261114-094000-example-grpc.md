## Objective
Show cameo's protobuf interop on a gRPC API anyone can call for free.

## Progress
- [x] Found a free service: grpcb.in (moul/grpcbin), `hello.HelloService`,
      on port 9001 with TLS and 9000 without; both answered on 2026-11-14
- [x] `examples/grpc`: the script declares the messages as classes and
      awaits the calls; the Go program passes the messages on as they are
- [x] A test against a service on this machine, so CI needs no network
- [x] A module of its own, run by `make tests`

## Obstacles
- **Issue:** `prog.Descriptor("Hello::HelloResponse")` said "no class"
  right after `Load`.
  **Resolution:** A script defines its classes when it runs: the module
  is defined, `Run` is called, then the descriptor is read.

## Outcomes

  may go away, which the README says by naming it as one.
- cameo's own `go.mod` is unchanged.
