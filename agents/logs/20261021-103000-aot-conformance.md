## Objective
The conformance suite doc/design/aot.md promised: every example, site
sample and CRuby benchmark case run on the interpreter and compiled, and
the outputs compared, so that each later step of the compiler has a check
that could turn red.

## Progress
- [x] run.rb collects the 920 scripts, builds a package per script and one binary that imports them all
- [x] Runs each script with a compiled method twice, compares output and exit status, tells nondeterminism from a difference
- [x] make conformance
- [x] Run: 61 of 920 scripts compile a method (3 examples, 58 benchmarks, no site sample); all 61 print the same

## Obstacles
- **Issue:** A package per script inside the module would be 900 packages to `go vet ./...` and `go test ./...`.
  **Resolution:** They go under bin/_conformance, which the Go tool's `./...` ignores and an import path still reaches.
- **Issue:** Most of CRuby's benchmarks print nothing, so two runs that printed the same proved little, and a compiled `add` made to return one more passed the examples: their fib adds a zero somewhere, which the overflow check takes for an overflow and leaves to the interpreter.
  **Resolution:** Both runs go through a generated main that prints the script's last value after its output. With the wrong `add`, app_fib then reports `=> 11405773` against the interpreter's `=> 5702887`; restored.

## Outcome

and in the design document.
