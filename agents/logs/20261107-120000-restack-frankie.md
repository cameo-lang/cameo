**Started:** 2026-11-07 12:00:00

**Used Models:** Opus
**Token usage (Estimated):** 600k input, 80k output

## Objective
Replay the ten commits of the frankie branch on main in a new order, as a
stack of pull requests: Kernel's private functions, minispec, irb's Alt
chords, a new readline package (Cameo::Kernel::Readline), methods, File
I/O with File.write, a library opening a Go module, rack without a
server, io/httpd feeding rack, and frankie on rack alone.

## Progress
- [x] Kernel private, minispec, irb Alt chords, replayed
- [x] readline: irb's line editor in src/readline, history file and limit, Cameo::Kernel::Readline
- [x] methods, with the Kernel-private parts that depend on it
- [x] File I/O with the --io policy moved down from io/httpd, and File.write
- [x] A library opens a Go module, its test moved from HTTPD to JSON
- [x] rack with Rack::Handler; io/httpd registers with it; frankie serves on Rack::Handler.default
- [x] make check green on each branch but irb Alt chords, which ran its own tests

## Obstacles
- **Issue:** Kernel private was written after methods and minispec, and used both.
  **Resolution:** its parts on instance_methods' listing and the method-list doc moved into the methods step.
- **Issue:** File I/O used the I/O policy (AllowIO, --io, IOAllowed) that came with io/httpd, now later.
  **Resolution:** the policy moved into the File I/O step; Stopped, FormatError and Done, which only httpd uses, stayed with httpd.
- **Issue:** frankie called HTTPD.serve, and a cameo value cannot hold a registry of servers.
  **Resolution:** Rack::Handler in rack's Go part, kept in the run's state; io/httpd registers from a cameo part of its own.
- **Issue:** scripted multi-line edits with Ruby's %q{} broke on unbalanced braces in Go code.
  **Resolution:** the Edit tool for those.

## Outcome
Ten stacked pull requests, the top three not set to merge on their own.

## Insights
A commit that grew on top of others carries hunks of theirs; replaying it
lower in a stack means moving those hunks up into the commit they belong
to, and rewording its message where it named what is not there yet.
