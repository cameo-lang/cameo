# Task: the lists inside an instruction run on cursors

**Started:** 2026-11-11 16:50:00
**Ended:** 2026-11-11 17:20:00
**Strategy:** Refactoring
**Status:** Completed
**Complexity:** Simple
**Used Models:** Fable 5.2
**Token usage (Estimated):** 400k input, 25k output

## Objective
Step 19 of `doc/design/ir.md`: an activation's position is data. The
evaluator called itself for the lists inside `IF`, `WHILE`, `BEGIN`,
`CASE`, `CASE_IN`, `INTERP`, `REGEXP`, `SAFE`, `AND`, `OR` and
`defined?`, and a `rescue`, a `break` and a `retry` travelled as Go
errors through those calls. Behaviour does not change.

## Progress
- [x] `eval/cursor.go`: `cursor`, the phases, `loop`, `ended`, `unwind`
- [x] Each instruction that holds lists enters a list and says with a
      phase what comes when it ends
- [x] `BEGIN` as phases: body, else, ensure, the classes and the body of
      each rescue clause, with what an ensure clause interrupted kept on
      its cursor
- [x] `runBody` and `runList` start an activation with one cursor
- [x] A script through every such instruction, with its output taken
      from the evaluator before the change
- [x] `make check`; conformance and ruby/spec statuses unchanged

## Obstacles
- **Issue:** `INTERP` evaluated a part, called `to_s` on it, and only
  then evaluated the next part, through a callback. Evaluating all
  parts first would change the order a script can see.
  **Resolution:** The string so far is on the value stack under the
  part being evaluated, and a part is made a string when its list ends.
- **Issue:** A pattern is matched by recursive Go code that evaluates
  the expressions inside it, a pinned value or a constant.
  **Resolution:** Those lists run through a nested call of the loop,
  on the same activation, so that a completion out of one still reaches
  the clauses around. They are short; they stay until patterns are
  worth phases of their own.
- **Issue:** `WHILE` took `break` and `next` only out of its body; one
  out of its condition went on to the loop around.
  **Resolution:** Kept: the cursor takes them in its body phase only.

## Outcome
Inside an activation nothing but a pattern's expressions is on the Go
stack. The conformance suite reports the same line as before
(`total 951 68 70 68 0 0 241`), and the ruby/spec statuses are the same
3,939 rows.
