### Adding cameo to a module {#go-install}

cameo needs Go 1.26.4 or later, and `go get` raises a module's `go` line to
that. In the module that will import the package:

``` sh
go get github.com/cameo-lang/cameo@v0.5.1
go mod tidy
```

`go mod tidy` adds cameo's own dependencies, `google.golang.org/protobuf`,
`github.com/go-ruby-parser/parser` and `golang.org/x/text`, to `go.sum`;
without it the build fails with "missing go.sum entry". Neither needs cgo.

### Load, Run and RunContext {#go-run}

`cameo.Load(path, env)` loads the script at `path`, parses and checks it, and
returns a `*cameo.Program`. `env`, a `cameo.Env`, is all of the host the
program reaches: it reads the script (`LoadFile`), its `puts` and `warn` write
to the Env's `Stdout` and `Stderr`, and the files it reads and writes, once
[file I/O is allowed](#ch-io), are the Env's `Files`. Package `cameo` touches
no file or stream of the host itself; the package `cameoio` has the Envs:
`cameoio.DefaultEnv()`, the machine's files from the working directory and the
standard streams, `cameoio.Streams(stdout, stderr)`, output alone, and
`cameoio.New(fsys, dir, stdin, stdout, stderr)`. A program that does not
import `cameoio` can show that no script reaches the host through cameo's
defaults. `cameo.LoadFromString(file, src, env)` loads a script the program
holds as a string, `file` naming it in error messages.

`Run` evaluates the script once, and its classes and methods stay loaded for
`Call`. `LastValue` returns the script's last top-level expression as `p`
shows it. `cameo.Run(path, env)` does `Load` and `Run` in one call, as the
`cameo` command does, and `cameo.RunFromString(file, src, env)`
`LoadFromString` and `Run`.

The program below loads `point.cameo` from the working directory:

``` {.cameo .hosted data-title="point.cameo"}
class Point
  int :x, :y

  def +(other)
    Point.new(x: x + other.x, y: y + other.y)
  end
end

def greet(name)
  "hello, #{name}"
end

puts "loaded"
Point.new(x: 1, y: 2)
```

``` go
package main

import (
    "fmt"
    "log"
    "os"

    "github.com/cameo-lang/cameo/src/cameo"
    "github.com/cameo-lang/cameo/src/cameoio"
)

func main() {
    prog, err := cameo.Load("point.cameo", cameoio.DefaultEnv())
    if err != nil {
        log.Fatal(err)
    }
    if err := prog.Run(); err != nil {
        log.Fatal(err)
    }
    last, _ := prog.LastValue()
    fmt.Println("last value:", last)

    hello, err := prog.Call(nil, "greet", "Go")
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(hello)

    pt, err := prog.Call("Point", "new", map[string]any{"x": 1, "y": 2})
    if err != nil {
        log.Fatal(err)
    }
    sum, err := prog.Call(pt, "+", pt)
    if err != nil {
        log.Fatal(err)
    }
    fmt.Printf("%T\n", sum)
    x, _ := prog.Call(sum, "x")
    fmt.Printf("%T %v\n", x, x)
}
```

``` output
loaded
last value: Point(x: 1, y: 2)
hello, Go
*dynamicpb.Message
int64 2
```

`RunContext(ctx)` is `Run` until the context ends. Then the script, and every
worker it started, stops at its next loop pass, method call or block call, no
`rescue` catches it, and `RunContext` returns the context's error.

``` go
package main

import (
    "context"
    "fmt"
    "log"
    "os"
    "time"

    "github.com/cameo-lang/cameo/src/cameo"
    "github.com/cameo-lang/cameo/src/cameoio"
)

func main() {
    prog, err := cameo.LoadFromString("spin.cameo", "loop { }", cameoio.DefaultEnv())
    if err != nil {
        log.Fatal(err)
    }
    ctx, cancel := context.WithTimeout(context.Background(), 100*time.Millisecond)
    defer cancel()
    err = prog.RunContext(ctx)
    fmt.Println(err)
}
```

``` output
context deadline exceeded
```

A host method that blocks is not interrupted: the script stops once the method
returns, so a method that waits on something watches the same context.

### Calling into a script {#go-call}

`prog.Call(recv, method, args...)` calls a method and returns its result as a
Go value. It runs the script first if `Run` has not. The receiver is one of:

-   `nil`, for the script's top-level methods:
    `prog.Call(nil, "greet", "Go")`;
-   a class name, for a class method: `prog.Call("Geo::Point", "new", …)`;
-   a `proto.Message` of a loaded class, such as an instance a previous `Call`
    returned;
-   any other Go value `ToValue` converts: `prog.Call("abc", "upcase")`
    returns `"ABC"`. A string that names a loaded class is that class.

The arguments are converted with `ToValue`, and the result with `ToGo`. `Call`
passes positional arguments only; a class without `initialize` also takes its
fields as a `map[string]any`, as the example above does.

### How Go values map to cameo values {#go-values}

`prog.ToValue(v)` converts a Go value to a cameo value (an `object.Value`),
and `prog.ToGo(v)` converts back.

| Go value                                    | cameo value                       | back in Go                               |
|---------------------------------------------|-----------------------------------|------------------------------------------|
| `nil`                                       | `nil`                             | `nil`                                    |
| `bool`                                      | `true`, `false`                   | `bool`                                   |
| `int`, `int8` … `int64`, `uint8` … `uint32` | Integer                           | `int64`                                  |
| `uint`, `uint64`, `*big.Int`                | Integer                           | `int64` when it fits, else `*big.Int`    |
| `float32`, `float64`                        | Float                             | `float64`                                |
| `string`                                    | String (UTF-8)                    | `string`                                 |
| `[]byte`                                    | String (binary)                   | `[]byte`                                 |
| `time.Time`                                 | Time                              | `time.Time`                              |
| `[]any`, `[]string`                         | Array                             | `[]any`                                  |
| —                                           | Set                               | `[]any`                                  |
| `map[string]any`, `map[any]any`             | Hash                              | `map[any]any`                            |
| `proto.Message` of a loaded class           | an instance of that class         | `proto.Message` (a `*dynamicpb.Message`) |
| `*cameo.Block`                              | Proc                              | `*cameo.Block`, whose `Call` runs it     |
| `object.Value`                              | itself                            | —                                        |
| —                                           | Symbol, Range, Class and the rest | the `object.Value` itself                |

Any other Go value is an error: "cannot convert struct {} to a cameo value". A
Hash's Symbol keys become strings in Go, as a Symbol does wherever a value
leaves cameo. A Hash that has no Go map form is an error: one with both `:a`
and `"a"` as keys, or with keys that are not comparable in Go, such as a Range
or a binary String.

### Protobuf messages both ways {#go-proto}

Every class a script defines is a protobuf message, with one field per
declared field. A field's number comes from a hash of its name, or from
`number:` in its declaration; see [Protobuf](#ruby-proto) on the Ruby page. A
class inside `module Geo` is the message `Point` in package `geo`.

-   `prog.Proto(name)` returns the `.proto` text of one class.
-   `prog.ProtoFiles()` returns the `.proto` files of every loaded class, one
    per package and keyed by file name, with the value envelope in
    `cameo/value.proto`. Compile them with `protoc` to get Go types with the
    same wire form.
-   `prog.Descriptor(name)` returns the class's
    `protoreflect.MessageDescriptor`, from which `dynamicpb` builds a message
    without generated code.
-   `prog.Encode(v)` writes any value, not only an instance, in the
    `cameo.Value` envelope; `prog.Decode` reads it back.
-   `protogen.Merge(registered, next)` (package
    `github.com/cameo-lang/cameo/src/protogen`) merges two definitions of one
    message, as two programs that share a store have: the fields both have
    stay as registered, and the fields only `next` has are added, numbered
    from their names. The [design document](#ch-design-language) says what it
    accepts.

``` {.cameo .hosted data-title="geo.cameo"}
module Geo
  class Point
    int :x, :y

    def norm2
      x * x + y * y
    end
  end
end
```

``` go
package main

import (
    "fmt"
    "log"
    "maps"
    "slices"

    "google.golang.org/protobuf/proto"
    "google.golang.org/protobuf/reflect/protoreflect"
    "google.golang.org/protobuf/types/dynamicpb"

    "github.com/cameo-lang/cameo/src/cameo"
    "github.com/cameo-lang/cameo/src/cameoio"
)

func check(err error) {
    if err != nil {
        log.Fatal(err)
    }
}

func main() {
    prog, err := cameo.Load("geo.cameo", cameoio.DefaultEnv())
    check(err)
    check(prog.Run())

    // The .proto text of one class, and the files of all of them.
    text, err := prog.Proto("Geo::Point")
    check(err)
    fmt.Print(text)
    files := prog.ProtoFiles()
    fmt.Println(slices.Sorted(maps.Keys(files)))

    // A message built in Go from the class's descriptor is an instance in
    // the script.
    desc, err := prog.Descriptor("Geo::Point")
    check(err)
    msg := dynamicpb.NewMessage(desc)
    msg.Set(desc.Fields().ByName("x"), protoreflect.ValueOfInt64(3))
    msg.Set(desc.Fields().ByName("y"), protoreflect.ValueOfInt64(4))
    n, err := prog.Call(msg, "norm2")
    check(err)
    fmt.Println(n)

    // An instance comes back as a proto.Message.
    pt, err := prog.Call("Geo::Point", "new", map[string]any{"x": 1, "y": 2})
    check(err)
    wire, err := proto.Marshal(pt.(proto.Message))
    check(err)
    fmt.Println(len(wire), "bytes")

    // Any value travels in the cameo.Value envelope.
    data, err := prog.Encode([]any{"a", int64(1), pt})
    check(err)
    back, err := prog.Decode(data)
    check(err)
    fmt.Println(len(back.([]any)), "elements")
}
```

``` output
package geo;

message Point {
  optional int64 x = 64843;
  optional int64 y = 64608;
}
[cameo/value.proto geo.proto]
25
8 bytes
3 elements
```

### Errors {#go-errors}

A script that does not check returns a `syntax.ErrorList` (package
`github.com/cameo-lang/cameo/src/syntax`) from `Load`, with every error and
its line. An exception that ends `Run` or `Call` returns a `*cameo.RunError`,
whose `Message` is formatted as the `cameo` command prints it and whose
`Unwrap` returns the exception, an `*object.Exception`.

``` go
package main

import (
    "errors"
    "fmt"
    "io"

    "github.com/cameo-lang/cameo/src/cameo"
    "github.com/cameo-lang/cameo/src/cameoio"
    "github.com/cameo-lang/cameo/src/syntax"
)

func main() {
    _, err := cameo.LoadFromString("bad.cameo", "@count = 1\n$total = 2\n", cameoio.Streams(io.Discard, io.Discard))
    var list syntax.ErrorList
    if errors.As(err, &list) {
        for _, e := range list {
            fmt.Printf("line %d: %s\n", e.Line, e.Msg)
        }
    }

    err = cameo.RunFromString("boom.cameo", "def half(n)\n  n / 0\nend\nhalf(4)\n", cameoio.Streams(io.Discard, io.Discard))
    var runErr *cameo.RunError
    if errors.As(err, &runErr) {
        fmt.Println(runErr.Message)
    }
}
```

``` output
line 1: @count = …: cameo has no instance variables; initialize sets a field with self.count = …
line 2: global variables are not supported
boom.cameo:1: divided by 0 (ZeroDivisionError)
```

### Concurrency {#go-concurrency}

Inside a script that includes `Cameo`, `async` runs a method call on another
goroutine, over copies of its receiver and arguments; see [async, await and
promises](#ruby-async). Every worker reaches the host's modules, so a host
method may run on several goroutines at once and must be safe for that.
`RunContext` stops the workers with the script.

``` {.cameo .hosted data-title="fetch.cameo"}
include Cameo

class Fetcher
  string :base

  def get(path)
    Http.get(base + path)
  end
end

f = Fetcher.new(base: "https://example.com")
jobs = ["/a", "/b", "/c"].map { |path| async f, :get, path }
p jobs.map { |job| await job }
```

``` go
package main

import (
    "fmt"
    "log"
    "os"
    "sync/atomic"

    "github.com/cameo-lang/cameo/src/cameo"
    "github.com/cameo-lang/cameo/src/cameoio"
)

func main() {
    prog, err := cameo.Load("fetch.cameo", cameoio.DefaultEnv())
    if err != nil {
        log.Fatal(err)
    }
    var calls atomic.Int64
    prog.Module("Http").Def("get", func(args []any, kwargs map[string]any, block *cameo.Block) (any, error) {
        calls.Add(1) // runs on each worker's goroutine
        return "body of " + args[0].(string), nil
    })
    if err := prog.Run(); err != nil {
        log.Fatal(err)
    }
    fmt.Println(calls.Load(), "calls")
}
```

``` output
["body of https://example.com/a", "body of https://example.com/b", "body of https://example.com/c"]
3 calls
```

### Promises: I/O in the host {#go-promises}

cameo does no I/O. A host method that does some, such as fetching a web page,
can return a *promise* instead of blocking: it makes one with
`prog.Promise()`, starts the work on a goroutine, and returns the promise at
once. The script holds the promise as an Integer and awaits it; the goroutine
settles it with `Resolve`, with a Go value that converts as a host method's
result does, or with `Fail`, with an error that `await` raises. The script
below runs one workflow per page, each awaiting its own fetch, so every
request is in flight while the workflows wait; [the async guide](#async-io)
shows the timeline. `Resolve` and `Fail` may be called from any goroutine,
once; a second call returns `cameo.ErrSettled`. This is
[examples/webfetch](https://github.com/cameo-lang/cameo/tree/main/examples/webfetch):

``` {.cameo .hosted file="examples/webfetch/webfetch.cameo" data-title="webfetch.cameo"}
include Cameo

class Flow
  # One workflow: fetch the page, then measure it. await parks this
  # workflow until the host settles the promise; the others run meanwhile.
  def run(url)
    page = await Web.fetch(url)
    "#{url}: #{page.size} bytes, #{page.lines.size} lines"
  rescue Web::FetchError => e
    "#{url}: #{e.message}"
  end
end

def fetch_all(urls)
  flow = Flow.new
  promises = urls.map { |url| async flow, :run, url }   # every workflow starts now
  await promises                                        # their lines, in order
end
```

``` go
// Command webfetch fetches web pages from a cameo script, one workflow per
// page. cameo does no I/O, so the host gives the script a Web module whose
// fetch starts the request on a goroutine and returns a promise at once; the
// host settles the promise from outside the script when the response is
// in. Each workflow awaits its own fetch, so every request is in flight
// while the script waits, and await returns each page or raises
// Web::FetchError.
//
// The script, webfetch.cameo, is built into the program, and cameo loads it
// through an Env of the program's own files.
//
//  go run ./examples/webfetch https://example.com https://example.org/missing
package main

import (
    "embed"
    "fmt"
    "io"
    "net/http"
    "os"

    "github.com/cameo-lang/cameo/src/cameo"
    "github.com/cameo-lang/cameo/src/cameoio"
    "github.com/spf13/afero"
)

//go:embed webfetch.cameo
var scripts embed.FS

// fetchAll runs the script's fetch_all over urls with client.
func fetchAll(client *http.Client, urls []string) ([]any, error) {
    env := cameoio.New(afero.FromIOFS{FS: scripts}, ".", nil, os.Stdout, os.Stderr)
    prog, err := cameo.Load("webfetch.cameo", env)
    if err != nil {
        return nil, err
    }
    web := prog.Module("Web")
    fetchError := web.Exception("FetchError")
    web.Def("fetch", func(args []any, kwargs map[string]any, block *cameo.Block) (any, error) {
        url, ok := args[0].(string)
        if !ok {
            return nil, fmt.Errorf("Web.fetch takes a URL, not %v", args[0])
        }
        promise := prog.Promise()
        go func() {
            resp, err := client.Get(url)
            if err != nil {
                promise.Fail(fetchError.New("%v", err))
                return
            }
            defer resp.Body.Close()
            if resp.StatusCode != http.StatusOK {
                promise.Fail(fetchError.New("%s", resp.Status))
                return
            }
            body, err := io.ReadAll(resp.Body)
            if err != nil {
                promise.Fail(fetchError.New("%v", err))
                return
            }
            promise.Resolve(string(body))
        }()
        return promise, nil
    })
    lines, err := prog.Call(nil, "fetch_all", urls)
    if err != nil {
        return nil, err
    }
    return lines.([]any), nil
}

func main() {
    lines, err := fetchAll(http.DefaultClient, os.Args[1:])
    if err != nil {
        fmt.Fprintln(os.Stderr, err)
        os.Exit(1)
    }
    for _, line := range lines {
        fmt.Println(line)
    }
}
```

The host API makes no promise that one `Program` can be used from several
goroutines at once. Give each goroutine of the host its own `Program`; loading
one takes microseconds.
