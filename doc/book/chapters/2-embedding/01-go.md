## Embedding cameo in a Go program {#ch-go}

::: source
from `doc/gh_pages/go.html`
:::

Part 1 lists the steps to embed cameo. This part takes them one at a time:

1.  [Add the interpreter package](#go-install) to your Go module.
2.  Optional: [give the script I/O](#ch-io) with the package `cameoio`, for
    files, network and the like.
3.  Optional: [give the script classes and modules of your host](#ch-native),
    written in Go.
4.  [Load a script and run it](#go-run), then [call into it](#go-call). The
    values that go in and out are [protobuf messages](#ch-proto).

The last chapters show what a script can do once it runs in your program:
[call a gRPC service](#ch-grpc), [pause and resume](#ch-pause), and
[run work with async and await](#ch-async).

### Adding cameo to a module {#go-install}

cameo needs Go 1.26.4 or later, and `go get` raises a module's `go` line to
that. In the module that will import the package:

``` sh
go get github.com/cameo-lang/cameo@v0.5.1
go mod tidy
```

`go mod tidy` adds cameo's own dependencies, `google.golang.org/protobuf`,
`github.com/go-ruby-parser/parser` and `golang.org/x/text`, to `go.sum`;
without it the build fails with "missing go.sum entry". Neither needs cgo.

### Load, Run and RunContext {#go-run}

`cameo.Load(path, env)` loads the script at `path`, parses and checks it, and
returns a `*cameo.Program`. `env`, a `cameo.Env`, is all of the host the
program reaches: it reads the script (`LoadFile`), its `puts` and `warn` write
to the Env's `Stdout` and `Stderr`, and the files it reads and writes, once
[file I/O is allowed](#ch-io), are the Env's `Files`. Package `cameo` touches
no file or stream of the host itself; the package `cameoio` has the Envs:
`cameoio.DefaultEnv()`, the machine's files from the working directory and the
standard streams, `cameoio.Streams(stdout, stderr)`, output alone, and
`cameoio.New(fsys, dir, stdin, stdout, stderr)`. A program that does not
import `cameoio` can show that no script reaches the host through cameo's
defaults. `cameo.LoadFromString(file, src, env)` loads a script the program
holds as a string, `file` naming it in error messages.

`Load` only reads and checks the script. `Run` evaluates its top-level code
once. `Run` does not change the loaded script: the classes and methods it
defines stay loaded, and `Call` uses them. `Run` on a program that
[paused](#ch-pause) continues where the run stopped. `LastValue` returns the script's last top-level expression as `p`
shows it. `cameo.Run(path, env)` does `Load` and `Run` in one call, as the
`cameo` command does, and `cameo.RunFromString(file, src, env)`
`LoadFromString` and `Run`.

The program below loads `point.cameo` from the working directory:

``` {.cameo .hosted data-title="point.cameo"}
class Point
  int :x, :y

  def +(other)
    Point.new(x: x + other.x, y: y + other.y)
  end
end

def greet(name)
  "hello, #{name}"
end

puts "loaded"
Point.new(x: 1, y: 2)
```

``` go
package main

import (
    "fmt"
    "log"
    "os"

    "github.com/cameo-lang/cameo/src/cameo"
    "github.com/cameo-lang/cameo/src/cameoio"
)

func main() {
    prog, err := cameo.Load("point.cameo", cameoio.DefaultEnv())
    if err != nil {
        log.Fatal(err)
    }
    if err := prog.Run(); err != nil {
        log.Fatal(err)
    }
    last, _ := prog.LastValue()
    fmt.Println("last value:", last)

    hello, err := prog.Call(nil, "greet", "Go")
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(hello)

    pt, err := prog.Call("Point", "new", map[string]any{"x": 1, "y": 2})
    if err != nil {
        log.Fatal(err)
    }
    sum, err := prog.Call(pt, "+", pt)
    if err != nil {
        log.Fatal(err)
    }
    fmt.Printf("%T\n", sum)
    x, _ := prog.Call(sum, "x")
    fmt.Printf("%T %v\n", x, x)
}
```

``` output
loaded
last value: Point(x: 1, y: 2)
hello, Go
*dynamicpb.Message
int64 2
```

`RunContext(ctx)` is `Run` until the context ends. Then the script, and every
worker it started, stops at its next loop pass, method call or block call, no
`rescue` catches it, and `RunContext` returns the context's error.

``` go
package main

import (
    "context"
    "fmt"
    "log"
    "os"
    "time"

    "github.com/cameo-lang/cameo/src/cameo"
    "github.com/cameo-lang/cameo/src/cameoio"
)

func main() {
    prog, err := cameo.LoadFromString("spin.cameo", "loop { }", cameoio.DefaultEnv())
    if err != nil {
        log.Fatal(err)
    }
    ctx, cancel := context.WithTimeout(context.Background(), 100*time.Millisecond)
    defer cancel()
    err = prog.RunContext(ctx)
    fmt.Println(err)
}
```

``` output
context deadline exceeded
```

A host method that blocks is not interrupted: the script stops once the method
returns, so a method that waits on something watches the same context.

### Calling into a script {#go-call}

`prog.Call(recv, method, args...)` calls a method and returns its result as a
Go value. It runs the script first if `Run` has not. The receiver is one of:

-   `nil`, for the script's top-level methods:
    `prog.Call(nil, "greet", "Go")`;
-   a class name, for a class method: `prog.Call("Geo::Point", "new", …)`;
-   a `proto.Message` of a loaded class, such as an instance a previous `Call`
    returned;
-   any other Go value `ToValue` converts: `prog.Call("abc", "upcase")`
    returns `"ABC"`. A string that names a loaded class is that class.

The arguments are converted with `ToValue`, and the result with `ToGo`. `Call`
passes positional arguments only; a class without `initialize` also takes its
fields as a `map[string]any`, as the example above does.

### Errors {#go-errors}

A script that does not check returns a `syntax.ErrorList` (package
`github.com/cameo-lang/cameo/src/syntax`) from `Load`, with every error and
its line. An exception that ends `Run` or `Call` returns a `*cameo.RunError`,
whose `Message` is formatted as the `cameo` command prints it and whose
`Unwrap` returns the exception, an `*object.Exception`.

``` go
package main

import (
    "errors"
    "fmt"
    "io"

    "github.com/cameo-lang/cameo/src/cameo"
    "github.com/cameo-lang/cameo/src/cameoio"
    "github.com/cameo-lang/cameo/src/syntax"
)

func main() {
    _, err := cameo.LoadFromString("bad.cameo", "@count = 1\n$total = 2\n", cameoio.Streams(io.Discard, io.Discard))
    var list syntax.ErrorList
    if errors.As(err, &list) {
        for _, e := range list {
            fmt.Printf("line %d: %s\n", e.Line, e.Msg)
        }
    }

    err = cameo.RunFromString("boom.cameo", "def half(n)\n  n / 0\nend\nhalf(4)\n", cameoio.Streams(io.Discard, io.Discard))
    var runErr *cameo.RunError
    if errors.As(err, &runErr) {
        fmt.Println(runErr.Message)
    }
}
```

``` output
line 1: @count = …: cameo has no instance variables; initialize sets a field with self.count = …
line 2: global variables are not supported
boom.cameo:1: divided by 0 (ZeroDivisionError)
```
