## ex1: a Go program that embeds cameo {#ch-example-ex1}

::: source
from `examples/ex1/README.md`
:::

The smallest program that does the three things an embedding is for: it
defines a class in Go, runs a script that uses the class, and calls a method
the script defines.

``` sh
go run ./examples/ex1                # runs hello.cameo, which is built in
go run ./examples/ex1 mine.cameo     # runs a script of your own
```

    Hello, world!
    HELLO, cameo!
    Hello, again!
    from Go: Welcome, Go!

| File                                       | Holds                                                                                            |
|--------------------------------------------|--------------------------------------------------------------------------------------------------|
| [greet.proto](https://github.com/cameo-lang/cameo/blob/main/examples/ex1/greet.proto)                 | the message behind the class: one field, `greeting`                                              |
| [greetpb/greet.pb.go](https://github.com/cameo-lang/cameo/blob/main/examples/ex1/greetpb/greet.pb.go) | its Go code, generated by `make proto` and committed                                             |
| [main.go](https://github.com/cameo-lang/cameo/blob/main/examples/ex1/main.go)                         | registers the class `Greeter` with two methods in Go, loads the script, runs it, calls `welcome` |
| [hello.cameo](https://github.com/cameo-lang/cameo/blob/main/examples/ex1/hello.cameo)                 | the script                                                                                       |

`Greeter.new(greeting: "Hello")` in the script is a `*greetpb.Greeter` in Go.
A method gets a copy of the instance it is called on, so `louder` returns a
new `Greeter` and the script's `greeter` stays as it was: cameo values are
immutable, also across the border to Go.

To try it on a script of your own, write one that uses `Greeter`:

``` ruby
names = %w[Ada Grace Barbara]
hi = Greeter.new(greeting: "Hi")
names.each { |name| puts hi.greet(name) }
```
