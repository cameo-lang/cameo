## Enabling I/O {#ch-io}

::: source
from `doc/gh_pages/io.html`
:::

A script does no I/O of its own. What it may read and write is decided by
whoever runs it: a flag on the command line, or two calls in the Go program
that embeds it.

1.  [What a script can do by default](#io-default)
2.  [On the command line: --io](#io-cli)
3.  [From a Go program: AllowIO and the Env's files](#io-go)
4.  [Everything else: a module of Go functions](#io-host)

### What a script can do by default {#io-default}

It computes, and it writes to the two streams its host gave it: `puts`,
`print`, `p` and `warn`. It has no `ENV`, no sockets, no `system` and no
backticks. `File` handles paths as strings, and its methods that touch a file
do not exist; the error says how to get them.

``` {.ruby .cameo}
p File.respond_to?(:read)
p File.basename("/home/ada/notes.txt")      # a path is only a string

begin
  File.read("notes.txt")
rescue NoMethodError => e
  puts e.message
end
```

``` output
false
"notes.txt"
undefined method 'read' for class File: the host allows no file I/O; run the script with cameo --io=file, or let the program say AllowIO("file") and load it with a cameo.Env that has files (see https://15b.it/io)
```

So a script from an untrusted source can be run as it is: the worst it does is
compute for too long, and [`RunContext`](#go-run) stops that.

### On the command line: --io {#io-cli}

`cameo --io script.cameo` allows every kind of I/O, and
`cameo --io=file script.cameo` the kinds named, separated by commas. The flag
goes before the script, and before `irb`, `resume` and `debug`.

With a file `notes.txt` of three lines,

``` {.output data-name="notes.txt"}
three
lines
here
```

and a script `io.cameo`,

``` {.ruby data-name="io.cameo"}
text = File.read("notes.txt")
puts text.lines.size
File.write("copy.txt", text.upcase)
File.open("copy.txt") { |f| puts f.gets }
```

``` sh
cameo --io=file io.cameo
```

``` output
3
THREE
```

| Kind               | Gives a script                                                                                                                                                           |
|--------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `file`             | `File.read`, `File.open` for reading, and `File.write`, on the machine's files, relative paths from the working directory. A path is only a path: `"|cmd"` runs nothing. |
| `network`, `popen` | Nothing yet. The flag takes the names, and no library of cameo's uses them so far.                                                                                       |

Without the flag the same script stops at its first line, with the message
above, and exits with status 1.

### From a Go program: AllowIO and the Env's files {#io-go}

A program that embeds cameo says which files a script may use with the
`cameo.Env` it loads the script with, and allows the kind with
`prog.AllowIO("file")`. Both are needed. The Env's `Files` is an
[afero](https://github.com/spf13/afero) `Fs` and the directory a relative path
starts at: the disk, one directory of it, a read-only view, or memory.
`cameoio.New(fsys, dir, stdin, stdout, stderr)` makes such an Env, and
`cameoio.DefaultEnv()` is the machine's own files from the working directory,
which is what the command line runs scripts with.

The example
[examples/io](https://github.com/cameo-lang/cameo/tree/main/examples/io) gives
this script a file system in memory:

``` {.cameo .hosted file="examples/io/notes.cameo" data-title="notes.cameo"}
# The script reads and writes files as in Ruby. Which files those are is
# the Go program's choice.
text = File.read("notes.txt")
puts "#{text.lines.size} lines"
File.write("shout.txt", text.upcase)
File.open("shout.txt") { |f| puts f.gets }
```

``` {.go file="examples/io/main.go" data-title="main.go"}
// Command io lets a script read and write files, in a file system the Go
// program chooses. A script does no I/O unless the program that runs it
// allows a kind of it: here the kind "file", with a file system in
// memory that holds one file.
//
//  go run ./examples/io
package main

import (
    _ "embed"
    "fmt"
    "io"
    "os"

    "github.com/cameo-lang/cameo/src/cameo"
    "github.com/cameo-lang/cameo/src/cameoio"
    "github.com/spf13/afero"
)

//go:embed notes.cameo
var script string

// run runs the script with the files of fsys, relative paths read from
// dir.
func run(fsys afero.Fs, dir string, stdout, stderr io.Writer) error {
    // Both are needed: a file system in the Env, and the kind allowed.
    // The file system may be the disk (afero.NewOsFs), one directory of
    // it (afero.NewBasePathFs), a read-only view (afero.NewReadOnlyFs) or
    // memory, as here.
    prog, err := cameo.LoadFromString("notes.cameo", script, cameoio.New(fsys, dir, nil, stdout, stderr))
    if err != nil {
        return err
    }
    prog.AllowIO("file")
    return prog.Run()
}

func main() {
    fsys := afero.NewMemMapFs()
    if err := afero.WriteFile(fsys, "/work/notes.txt", []byte("three\nlines\nhere\n"), 0o644); err != nil {
        fmt.Fprintln(os.Stderr, err)
        os.Exit(1)
    }
    if err := run(fsys, "/work", os.Stdout, os.Stderr); err != nil {
        fmt.Fprintln(os.Stderr, err)
        os.Exit(1)
    }
    shout, _ := afero.ReadFile(fsys, "/work/shout.txt")
    fmt.Printf("the script wrote %d bytes into the file system\n", len(shout))
}
```

``` sh
go run ./examples/io
```

``` output
3 lines
THREE
the script wrote 17 bytes into the file system
```

Given `afero.NewReadOnlyFs(fsys)` instead, the script reads the file and its
`File.write` raises.

### Everything else: a module of Go functions {#io-host}

Any other I/O, a database, an HTTP request, a queue, the script gets as a
module the Go program defines: the program decides what the function does and
what the script may ask of it. A function that takes time returns a promise,
and the script awaits it while its other work goes on.

-   [Native code](#native-host) shows a module of Go functions.
-   [Embedding in Go](#go-promises) has a program that fetches web pages for a
    script, each request on its own goroutine.
-   [gRPC](#ch-grpc) calls a public service the same way.
