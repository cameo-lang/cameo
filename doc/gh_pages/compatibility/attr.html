attr — attr_accessor

The checker refuses attr_reader, attr_writer, attr_accessor and attr. A field declaration defines the reader, and there are no setters.

What cameo refuses

Each is refused by name, with the field declaration to use.

class Person
  attr_accessor :name
end
script.cameo:2: attr_accessor is not supported: a field declaration defines its reader, and there are no setters (see https://15b.it/attr)

Why

attr_reader reads an instance variable, which cameo does not have (ivar), and a writer changes an object, which no cameo value allows (mut). A field declaration says what the reader would and more: the field's type, which every value is held to, and its place in the object's protobuf message.

What to write instead

Declare the field with its type: string :name defines name. with(name: …) returns a copy with the field changed.

class Person
  string :name
end

ada = Person.new(name: "Ada")
grace = ada.with(name: "Grace")
puts ada.name, grace.name
Ada
Grace
