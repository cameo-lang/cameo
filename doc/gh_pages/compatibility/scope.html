scope — scoped constants

A constant is assigned inside its module. A::B = 1 from outside A is refused.

What cameo refuses

The assignment is refused before the script runs. Reading A::B works as in Ruby.

module Config
end
Config::LIMIT = 10
script.cameo:3: assignment to a scoped constant is not supported: define it inside its module (see https://15b.it/scope)

Why

A module, like a class, is built in its body and sealed when the body ends. An assignment from outside would add to it later, from anywhere in the script, so what a module holds would depend on what ran before.

What to write instead

Assign the constant in the module's body.

module Config
  LIMIT = 10
end
p Config::LIMIT
10

The rule: cameo and Ruby, rejected before the script runs. Every code, and how many examples of ruby/spec each stops.
