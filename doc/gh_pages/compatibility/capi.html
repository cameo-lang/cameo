capi — the C API

cameo loads no native code. Ruby's C API and C extensions are left out, and so are Fiddle and FFI.

What cameo refuses

A library that needs a C extension raises a LoadError, as any library cameo does not build in does.

require "fiddle"
script.cameo:1: cannot load such file -- fiddle (LoadError)

Why

cameo is an interpreter written in Go, embedded in Go programs, and builds its libraries in. Native code loaded by a script would escape every limit the host sets, and could not be paused or resumed.

What to write instead

The Go program gives a script what native code would: a host module whose methods are Go functions; see Native code.

require "digest"
p Digest::SHA256.hexdigest("cameo")[0, 16]
"85126641179f4032"
