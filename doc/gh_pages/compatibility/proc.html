Compatibility › proc

proc — the process

A cameo script does not reach the process it runs in: Process, Signal, ENV, GC, ObjectSpace, fork, system, exec and backticks are left out.

What cameo refuses

Backticks and fork are refused before the script runs. The constants and methods are absent, so a script fails when it reaches one.

puts `date`
script.cameo:1: backtick commands are not supported: cameo has no shell (see https://15b.it/proc)
puts ENV["HOME"]
script.cameo:1: uninitialized constant ENV (NameError)

Why

cameo runs inside a Go program, which decides what a script may touch: a server may run scripts its users wrote, and a script's run may be paused on one machine and resumed on another. Environment variables, signals and child processes belong to the process that happens to run it, and would neither be safe to hand out nor survive a resume.

What to write instead

The host gives the script what it needs: arguments in ARGV, values through a host module whose methods the Go program writes, and work that waits through promises. async takes the place of fork; see Embedding in Go and Async.

p ARGV
puts Time.now.year > 2000
[]
true
