next — external enumerators

An Enumerator has no next, peek or rewind.

What cameo refuses

The methods are absent, so a script fails when it reaches one.

e = [1, 2, 3].each
p e.next
script.cameo:2: undefined method 'next' for an instance of Enumerator (see https://15b.it/next) (NoMethodError)

Why

next advances an enumerator in place: the same value returns a different element each time, which no cameo value does. An Enumerator in cameo is a value like any other, and its methods that take a block, or return arrays, work as in Ruby.

What to write instead

Iterate with a block, or take what next would give with first, take, each_slice, each_cons or zip.

p [1, 2, 3].first
p [1, 2, 3].each_slice(2).to_a
p [1, 2, 3].each_cons(2).map { |a, b| b - a }
1
[[1, 2], [3]]
[1, 1]
