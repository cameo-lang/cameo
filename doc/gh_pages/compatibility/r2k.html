r2k — ruby2_keywords

cameo has no ruby2_keywords. A method that passes its arguments on takes keywords with **.

What cameo refuses

ruby2_keywords is an undefined method.

class Wrapper
  ruby2_keywords def call(*args)
    args
  end
end
script.cameo:2: undefined method 'ruby2_keywords' for class Wrapper (see https://15b.it/r2k) (NoMethodError)

Why

ruby2_keywords lets Ruby 2 code that passed keywords as a trailing Hash keep working in Ruby 3. cameo accepts current Ruby alone, where keywords are passed with ** or key: value, never as a trailing Hash, so there is nothing to bridge.

What to write instead

Take *args, **opts, &block and pass them on, or forward with ....

def inner(a, b: 2) = [a, b]
def wrap(*args, **opts) = inner(*args, **opts)
p wrap(1, b: 3)
[1, 3]
