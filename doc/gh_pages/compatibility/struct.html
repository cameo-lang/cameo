struct — Struct

cameo has no Struct. A class with typed fields is one: it takes its fields as keywords, compares by them, and prints them.

What cameo refuses

Struct is absent, so a script fails when it reaches it.

Point = Struct.new(:x, :y)
script.cameo:1: uninitialized constant Struct (NameError)

Why

A Struct's members can be set after it is made, which no cameo value allows, and it is a class made at run time from a list of names (meta). A class body with field declarations says the same, with a type for each field.

What to write instead

Declare a class with typed fields. with returns a copy with fields changed.

class Point
  int :x, :y
end

pt = Point.new(x: 1, y: 2)
p pt
p pt.with(y: 5)
Point(x: 1, y: 2)
Point(x: 1, y: 5)
