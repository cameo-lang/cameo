io — I/O

A script writes to standard output and standard error. IO, Dir, ARGF, STDIN and the reading and writing of files are not there, unless the host program allows their kind of I/O.

What cameo refuses

Without the host's leave, File.read is an undefined method, and its message says how a program allows it.

puts File.read("notes.txt")
script.cameo:1: undefined method 'read' for class File: the host allows no file I/O; run the script with cameo --io=file, or let the program say AllowIO("file") and give it a file system with FileSystem (NoMethodError)

Why

A program that embeds cameo decides what its scripts may touch, and by default they touch nothing outside their own output. A host allows file I/O with AllowIO("file") and gives a file system, its own disk, one directory of it, or memory; cameo --io=file gives the machine's. Where it is not allowed, the methods are absent rather than raising, so respond_to? tells a script what it may do.

What to write instead

Write with puts, print and p, or to STDOUT and STDERR. Read what the host gives: a host module, a promise, or files where the program allows them; see I/O.

STDOUT.puts "to standard output"
