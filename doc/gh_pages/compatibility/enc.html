enc — encodings

A String is UTF-8, binary (ASCII-8BIT) or US-ASCII. Other encodings, and converting between them, do not exist.

What cameo refuses

encode to another encoding raises, as does any encoding name cameo does not know.

p "héllo".encode("UTF-16LE")
script.cameo:1: unknown encoding name - UTF-16LE (ArgumentError)

Why

Text that reaches a cameo script comes from a Go host, a protobuf message or a file, and all three carry UTF-8. Ruby's hundred encodings, and the converters between them, would be a large part of the interpreter for text that arrives already decoded. Three encodings are enough to tell text from bytes.

What to write instead

Keep text in UTF-8, and bytes in a binary String: b gives the bytes of a String. A host converts text in another encoding before it gives it to the script.

s = "héllo"
p s.encoding
p s.bytesize
p s.b.encoding
#<Encoding:UTF-8>
6
#<Encoding:BINARY (ASCII-8BIT)>
