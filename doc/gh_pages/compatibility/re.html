re — regexps

Regular expressions use Ruby's syntax on cameo's own engine, which does not run lookbehind or backreferences.

What cameo refuses

A literal regexp with either is refused before the script runs; one built at run time raises when it is made.

p "price: 42"[/(?<=price: )\d+/]
script.cameo:1: This regexp is not supported in Cameo: /(?<=price: )\d+/ uses lookbehind (see https://15b.it/re)

Why

cameo's engine is built on Go's, which matches in time linear in the input: no pattern can make a script hang on a long string, which matters for a host that runs scripts it did not write. Lookbehind and backreferences are what such an engine cannot do.

What to write instead

Match the context and take a group, or check what a backreference would with Ruby code.

p "price: 42"[/price: (\d+)/, 1]
"42"
