lib — parts of libraries

cameo builds a library in without every part of it. Zlib's streams, Matrix#eigensystem and lup, Date::Infinity, URI.regexp, CGI cookies, OpenSSL beyond digests and Pathname's file system are left out.

What cameo refuses

A part left out is an undefined method or constant, as for any method a class does not have.

require "matrix"
p Matrix[[2, 0], [0, 3]].eigensystem
script.cameo:2: undefined method 'eigensystem' for an instance of Matrix (NoMethodError)

Why

A library's row in stdlib.md says what cameo builds in of it and what it leaves out, and why: a part that does I/O (Zlib's streams, Pathname's file system), keeps state that changes (CGI's cookie jar), or needs a value cameo does not have (Date::Infinity) does not fit; a part few scripts use was not worth its cost.

What to write instead

Use the parts the library's row lists. stdlib.md names the alternative where there is one.

require "matrix"
m = Matrix[[2, 0], [0, 3]]
p m.determinant
p m * m
6
Matrix[[4, 0], [0, 9]]

The rule: the standard library in cameo. Every code, and how many examples of ruby/spec each stops.
