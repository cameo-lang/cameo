data — Data

cameo has no Data. A class with typed fields is cameo's Data, and its with is Data's.

What cameo refuses

Data is absent, so a script fails when it reaches it.

Point = Data.define(:x, :y)
script.cameo:1: uninitialized constant Data (see https://15b.it/data) (NameError)

Why

Ruby's Data is an immutable value with named members, which is what every cameo instance already is. Data.define would be a second way to make one, without types, made at run time.

What to write instead

Declare a class with typed fields. Point.new(1, 2) with positional arguments needs an initialize that sets the fields.

class Point
  int :x, :y
end

a = Point.new(x: 1, y: 2)
p a.with(y: 3)
p a == Point.new(x: 1, y: 2)
Point(x: 1, y: 3)
true
