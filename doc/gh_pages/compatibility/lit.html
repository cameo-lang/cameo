Compatibility › lit

lit — no constructor

Some values are made with a literal alone: Range.new, Proc.new, String.new, Enumerator.new and Module.new do not exist.

What cameo refuses

The call fails when it runs, and the message says to use a literal.

r = Range.new(1, 3)
script.cameo:1: undefined method 'new' for class Range: use a literal (NoMethodError)

Why

The literal says the same thing in less, and cameo keeps one way to make such a value. Enumerator.new takes a block that yields to the enumerator as it is walked, which needs a value that changes as it goes (next); Module.new makes a module at run time (meta).

What to write instead

Write (1..3), proc { } or -> { }, "", and a module with a name.

p (1..3).to_a
square = proc { |x| x * x }
p square.call(4)
