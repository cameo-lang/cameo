bobj — BasicObject subclasses

A class cannot subclass BasicObject.

What cameo refuses

class X < BasicObject is refused before the script runs; inside a module, or with Class.new(BasicObject), the refusal is a CameoError when the definition runs.

class Proxy < BasicObject
end
script.cameo:1: class Proxy < BasicObject: a subclass of BasicObject is not supported; use method_missing in an ordinary class (see https://15b.it/bobj)

Why

A subclass of BasicObject is a blank slate without Object's methods, used mostly for proxies that forward every call. cameo does not make objects without Object's methods: every value can be compared, printed, and written into a dump.

What to write instead

method_missing in an ordinary class catches the calls a proxy forwards.

class Recorder
  list :calls, of: :string

  def method_missing(name, *args) = with(calls: calls + [name.to_s])
  def respond_to_missing?(name, include_private = false) = true
end

r = Recorder.new.open.close
p r.calls
["open", "close"]
