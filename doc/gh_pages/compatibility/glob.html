Compatibility › glob

glob — global variables

cameo has no global variables, the special ones ($~, $1, $!) among them. $stdout and $stderr exist: they are STDOUT and STDERR.

What cameo refuses

A global variable, read or assigned, is refused before the script runs.

$count = 0
script.cameo:1: global variables are not supported (see https://15b.it/glob)
"2026-11-16" =~ /(\d+)-(\d+)/
p $1
script.cameo:2: global variables are not supported (see https://15b.it/glob)

Why

A global variable is state any method can change, which cameo has none of, and the special ones are set behind the script's back by a match or a rescue. Values that only flow through arguments and return values are what lets a run pause into a dump, and a worker run with a copy of what it was given.

What to write instead

A constant for a value that does not change, a local or an argument for one that does, rescue => e for the exception, and the MatchData that match returns for the groups.

LIMIT = 3
m = "2026-11-16".match(/(\d+)-(\d+)/)
p m[1], m[2]
p LIMIT
"2026"
"11"
3
