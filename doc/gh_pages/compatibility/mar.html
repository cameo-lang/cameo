mar — Marshal

Marshal writes and reads cameo's wire form, protobuf, not Ruby's Marshal bytes. A value dumped by cameo loads in cameo; bytes Ruby wrote do not.

What cameo refuses

Loading Ruby's bytes raises an ArgumentError, as Ruby's Marshal.load does for data it cannot read.

p Marshal.load("\x04\bi\x06".b)
script.cameo:1: incompatible marshal data: proto: cannot parse invalid wire-format data (ArgumentError)

Why

Every cameo value already has a wire form, the one dumps, workers and hosts use, and Marshal is that form under Ruby's name. Ruby's format records objects by class name and instance variables, which a cameo object does not have, so it could only be read approximately.

What to write instead

Use Marshal within cameo, to copy or store a value, and JSON or protobuf to exchange data with Ruby.

data = Marshal.dump({ "a" => [1, 2] })
p Marshal.load(data)
{"a" => [1, 2]}
