Compatibility › vis

vis — visibility

Every method a script defines is public. The checker refuses private, protected, public and module_function, and the method lists by visibility do not exist.

What cameo refuses

A visibility keyword, with or without method names, is refused by name.

class Account
  def balance = 10

  private

  def secret = 42
end
script.cameo:4: private is not supported: every method is public (see https://15b.it/vis)

Why

Visibility guards an object's state from callers that would change it. A cameo object's fields cannot change, so no caller can break one by calling a method, and a method a class keeps for itself does no harm when another calls it. One kind of method also keeps send, respond_to? and methods simple: what a value can do is what it lists.

Kernel's functions, puts and require among them, are private, as in Ruby, so that they stay out of every value's methods.

What to write instead

Drop the keyword. A method meant for the class alone says so in its name or its comment.

class Account
  int :cents, default: 1050

  def balance = format("%.2f", cents / 100.0)
end

puts Account.new.balance
10.50
