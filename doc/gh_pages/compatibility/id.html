id — identity and freezing

A value has no identity apart from what it holds. equal?, object_id and __id__ do not exist, frozen? is true for everything, and FrozenError never happens.

What cameo refuses

The methods are absent, so a script fails when it reaches one.

a = "x"
p a.equal?(a)
script.cameo:2: undefined method 'equal?' for an instance of String (NoMethodError)

Why

Identity matters when a value can change: two variables that hold the same object see each other's changes, and two equal objects do not. A cameo value never changes, so two equal values behave alike in every way, and the interpreter is free to copy one, as it does for a worker, or to share one, as a dump does. Asking which object a value is would answer differently from run to run.

What to write instead

Compare with ==: arrays, hashes and instances are equal when their contents are, and hash alike.

a = [1, 2]
b = [1, 2]
p a == b
p a.eql?(b)
p a.hash == b.hash
