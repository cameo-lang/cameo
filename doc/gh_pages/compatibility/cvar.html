cvar — class variables

cameo has no class variables. @@x, read or assigned, is refused.

What cameo refuses

A class variable is refused before the script runs.

class Widget
  @@made = 0
end
script.cameo:2: class variables are not supported (see https://15b.it/cvar)

Why

A class variable is state that every instance and subclass shares and any of them may change, which cameo has none of. A class is built in its body and sealed when the body ends: what it holds is set there, or by a class method the body calls.

What to write instead

A constant for a value that never changes, or a class attribute, which the class body sets, for a setting of the class.

class Widget
  KINDS = %w[button slider]

  attribute :default_kind, default: "button"
end

p Widget::KINDS
p Widget.default_kind
["button", "slider"]
"button"
