Extending cameo with native code

Go code reaches a script in three ways: a module the host gives one program, a class the host registers for every program in its process, and a builtin class in cameo's standard library.

  1. From a host: modules of Go methods
  2. Classes from a host
  3. Inside cameo: a builtin class

From a host: modules of Go methods

Between Load and Run, a host defines modules for the script:

  • prog.Module(name) defines the module name as a constant at the script's top level, as Math is, and returns a *cameo.Module. A script cannot redefine or reopen it.
  • mod.Def(name, fn) defines the method the script calls as Name.name(args). fn is an cameo.Func, func(args []any, kwargs map[string]any) (any, error): it gets the positional and keyword arguments as Go values, as ToGo converts them, except that a Symbol is a string and a Hash with String or Symbol keys is a map[string]any. What it returns converts as Call's arguments do.
  • mod.Exception(name) defines the exception class Name::name, a StandardError. Its New(format, args...) returns the error that raises it when fn returns it. Any other error raises RuntimeError with the error's text.
package main

import (
	"log"
	"os"
	"strings"

	"github.com/radiospiel/cameo/src/cameo"
)

const script = `
puts Text.shout("hello", times: 2)
begin
  Text.shout(42)
rescue Text::Invalid => e
  puts "rescued: #{e.message}"
end
`

func main() {
	prog, err := cameo.Load("text.cameo", script, os.Stdout, os.Stderr)
	if err != nil {
		log.Fatal(err)
	}
	text := prog.Module("Text")
	invalid := text.Exception("Invalid")
	text.Def("shout", func(args []any, kwargs map[string]any) (any, error) {
		s, ok := args[0].(string)
		if !ok {
			return nil, invalid.New("shout takes a String, not %T", args[0])
		}
		times := int64(1)
		if n, ok := kwargs["times"].(int64); ok {
			times = n
		}
		return strings.Repeat(strings.ToUpper(s)+"!", int(times)), nil
	})
	if err := prog.Run(); err != nil {
		log.Fatal(err)
	}
}

Workers that async starts call host methods on goroutines of their own, so a host method may run on several at once. One that blocks keeps the script from stopping until it returns: watch the context the host passed to RunContext.

A worked example: ark's Spicy.tools

ark runs scripts that call tools on cameo, in parts/golang/agentic/src/coderuby/amber.go. Its defineSpicy gives every script the module Spicy:

  • Spicy.tools alone returns the list of tools; Spicy.tools("search", { "q" => "x" }) or Spicy.tools("search", q: "x") calls one, merging the Hash and the keywords into the tool's JSON input.
  • Every failure returns toolError.New(…), so a script rescues Spicy::ToolError.
  • The host runs the script with RunContext and passes the same context.Context to the tool call, so a cancelled run reaches a tool that is still working.

Classes from a host

A host registers a class of its own with cameo.Register. The class's data layout is a protobuf message, generated with protoc-gen-go, and its methods are Go functions.

1. The message

Write the fields as a protobuf message:

syntax = "proto3";

package example.geo;

option go_package = "example.com/geo/geopb";

message Point {
  int64 x = 1;
  int64 y = 2;
}

2. The Go type

Generate the Go type with protoc and protoc-gen-go:

go install google.golang.org/protobuf/cmd/protoc-gen-go@latest
protoc --go_out=. --go_opt=module=example.com/geo geo.proto

This writes geopb/geo.pb.go, with the type geopb.Point.

3. Register the class

Register the class in an init function, then load scripts as usual. Here the script uses Geo::Point, and Go creates one through Call:

package main

import (
	"fmt"
	"log"
	"os"

	"example.com/geo/geopb"
	"github.com/radiospiel/cameo/src/cameo"
)

func init() {
	cameo.Register("Geo::Point", &geopb.Point{}).
		DefineMethod("norm2", func(p *geopb.Point, args []any, kwargs map[string]any) (any, error) {
			return p.X*p.X + p.Y*p.Y, nil
		}).
		DefineMethod("moved", func(p *geopb.Point, args []any, kwargs map[string]any) (any, error) {
			p.X += args[0].(int64) // p is a copy; the changed copy is the result
			return p, nil
		}).
		DefineClassMethod("origin", func(args []any, kwargs map[string]any) (any, error) {
			return &geopb.Point{}, nil
		})
}

const script = `
pt = Geo::Point.new(x: 3, y: 4)
p pt.norm2
p pt.moved(1).x, pt.x
p Geo::Point.origin.with(y: 2)
p Geo::Point.new.x
`

func main() {
	prog, err := cameo.Load("geo.cameo", script, os.Stdout, os.Stderr)
	if err != nil {
		log.Fatal(err)
	}
	if err := prog.Run(); err != nil {
		log.Fatal(err)
	}
	pt, err := prog.Call("Geo::Point", "new", map[string]any{"x": 5, "y": 12})
	if err != nil {
		log.Fatal(err)
	}
	fmt.Printf("%T x=%d\n", pt, pt.(*geopb.Point).X) // a registered class leaves cameo as its generated type
}

The rules

  • The class's fields are the message's. Every proto3 scalar type is supported. Repeated fields are lists, and maps take a scalar key. Enums must be numbered from 0 without a gap; their values become symbols (COLOR_RED is :red). A field may hold a message whose class was registered earlier, or the message itself. oneof is not supported.
  • Unset fields read as they do in Go. A field without presence reads as its zero value, so Geo::Point.new.x is 0. A field with presence (optional, or a message) reads as nil.
  • Methods get copies. A method gets self as the generated type: a copy it may change without changing the instance. A returned message of a registered type becomes an instance, so a method returns a changed copy, as moved does above. Arguments, results and errors convert as they do for a host module's methods.
  • Instances leave cameo as the generated type. Call and ToGo return a *geopb.Point, and a *geopb.Point passed in becomes an instance. async passes instances to workers like any other value.
  • Names are closed. A qualified name creates the modules it needs. A registered class is a constant in every program in the process, and no script can redefine it or define anything inside it.
  • Register before the first Load, from an init function. Register panics after that, or when the name or the message cannot be used. Both are mistakes in the host's code.

Instances of a class the script declares

A host can also return instances of a class the script declares itself: a proto.Message whose descriptor is a loaded class's becomes an instance of that class.

package main

import (
	"log"
	"os"

	"google.golang.org/protobuf/reflect/protoreflect"
	"google.golang.org/protobuf/types/dynamicpb"

	"github.com/radiospiel/cameo/src/cameo"
)

const script = `
class User
  string :name
  int :age

  def greeting = "#{name} is #{age}"
end

user = Users.find("ada")
puts user.greeting
p user.with(age: user.age + 1)
`

func main() {
	prog, err := cameo.Load("users.cameo", script, os.Stdout, os.Stderr)
	if err != nil {
		log.Fatal(err)
	}
	prog.Module("Users").Def("find", func(args []any, kwargs map[string]any) (any, error) {
		// The script declares User; Go builds one from its descriptor.
		desc, err := prog.Descriptor("User")
		if err != nil {
			return nil, err
		}
		user := dynamicpb.NewMessage(desc)
		user.Set(desc.Fields().ByName("name"), protoreflect.ValueOfString(args[0].(string)))
		user.Set(desc.Fields().ByName("age"), protoreflect.ValueOfInt64(36))
		return user, nil
	})
	if err := prog.Run(); err != nil {
		log.Fatal(err)
	}
}

Inside cameo: a builtin class

cameo's builtin classes live in src/stdlib, one file per area. A class is an *object.Class from object.NewClass(name, super):

  • c.Define(name, arity, fn) adds an instance method and c.DefineSingleton(name, arity, fn) a class method, where fn is an object.NativeFn: func(ctx object.Context, self object.Value, args []object.Value, kw *object.Map, block object.Value) (object.Value, error). An arity of -1 takes any number of arguments. ctx raises exceptions (ctx.Raise), calls methods and blocks, and renders values.
  • An instance is an object.Instance with the class and its Fields, as Pathname holds its path.
  • An install… function defines the methods and binds the constant, and stdlib.Install calls it.
  • puts and p render a builtin instance in src/eval/inspect.go, which names each such class: a native to_s or inspect is not enough.

This adds Money, an amount in cents, in src/stdlib/money.go:

package stdlib

import (
	"fmt"

	"github.com/radiospiel/cameo/src/object"
)

// MoneyClass is Money: an amount in cents, held as its instance's one field.
var MoneyClass = object.NewClass("Money", object.ObjectClass)

// installMoney defines Money.new(cents), Money#cents, Money#+ and Money#to_s.
func installMoney() {
	c := MoneyClass
	object.ObjectClass.Consts["Money"] = object.ClassValue(c)
	money := func(cents int64) object.Value {
		return object.InstanceValue(&object.Instance{Cls: c, Fields: []object.Value{object.Int(cents)}})
	}
	cents := func(v object.Value) int64 { return v.Instance().Fields[0].Int() }

	c.DefineSingleton("new", 1, func(ctx object.Context, self object.Value, args []object.Value, kw *object.Map, block object.Value) (object.Value, error) {
		n, err := wantInt(ctx, args[0], "")
		if err != nil {
			return object.Value{}, err
		}
		return money(n), nil
	})
	def(c, "cents", 0, func(ctx object.Context, self object.Value, args []object.Value, kw *object.Map, block object.Value) (object.Value, error) {
		return object.Int(cents(self)), nil
	})
	def(c, "+", 1, func(ctx object.Context, self object.Value, args []object.Value, kw *object.Map, block object.Value) (object.Value, error) {
		other, ok := args[0].AsInstance()
		if !ok || other.Cls != c {
			return object.Value{}, ctx.Raise(object.TypeError, "Money can't be added to %s", kindName(args[0]))
		}
		return money(cents(self) + cents(args[0])), nil
	})
	def(c, "to_s", 0, func(ctx object.Context, self object.Value, args []object.Value, kw *object.Map, block object.Value) (object.Value, error) {
		return object.String(MoneyToS(self)), nil
	})
}

// MoneyToS renders a Money as dollars and cents: $14.49.
func MoneyToS(v object.Value) string {
	n := v.Instance().Fields[0].Int()
	return fmt.Sprintf("$%d.%02d", n/100, n%100)
}

A builtin class's instances are not protobuf messages: they cannot be passed to async, which raises "Money is not a class with fields", and they reach a host as an *object.Instance. A new builtin also comes with an example in examples/, whose .expected output go test holds it to, and a line in doc/cameo-vs-ruby.md if Ruby has the class too.
