Extending amber with native code

There are two places to add Go code that a script calls: a module the host program gives one script, and a builtin class in amber's standard library, which every script has.

  1. From a host: modules of Go methods
  2. Classes from a host
  3. Inside amber: a builtin class

From a host: modules of Go methods

Between Load and Run, a host defines modules for the script:

  • prog.Module(name) defines the module name as a constant at the script's top level, as Math is, and returns a *amber.Module. A script cannot redefine or reopen it.
  • mod.Def(name, fn) defines the method the script calls as Name.name(args). fn is an amber.Func, func(args []any, kwargs map[string]any) (any, error): it gets the positional and keyword arguments as Go values, as ToGo converts them, except that a Symbol is a string and a Hash with String or Symbol keys is a map[string]any. What it returns converts as Call's arguments do.
  • mod.Exception(name) defines the exception class Name::name, a StandardError. Its New(format, args...) returns the error that raises it when fn returns it. Any other error raises RuntimeError with the error's text.
package main

import (
	"log"
	"os"
	"strings"

	"github.com/radiospiel/amber/src/amber"
)

const script = `
puts Text.shout("hello", times: 2)
begin
  Text.shout(42)
rescue Text::Invalid => e
  puts "rescued: #{e.message}"
end
`

func main() {
	prog, err := amber.Load("text.arb", script, os.Stdout, os.Stderr)
	if err != nil {
		log.Fatal(err)
	}
	text := prog.Module("Text")
	invalid := text.Exception("Invalid")
	text.Def("shout", func(args []any, kwargs map[string]any) (any, error) {
		s, ok := args[0].(string)
		if !ok {
			return nil, invalid.New("shout takes a String, not %T", args[0])
		}
		times := int64(1)
		if n, ok := kwargs["times"].(int64); ok {
			times = n
		}
		return strings.Repeat(strings.ToUpper(s)+"!", int(times)), nil
	})
	if err := prog.Run(); err != nil {
		log.Fatal(err)
	}
}

Workers that async starts call host methods on goroutines of their own, so a host method may run on several at once. One that blocks keeps the script from stopping until it returns: watch the context the host passed to RunContext.

A worked example: ark's Spicy.tools

ark runs scripts that call tools on amber, in parts/golang/agentic/src/coderuby/amber.go. Its defineSpicy gives every script the module Spicy:

  • Spicy.tools alone returns the list of tools; Spicy.tools("search", { "q" => "x" }) or Spicy.tools("search", q: "x") calls one, merging the Hash and the keywords into the tool's JSON input.
  • Every failure returns toolError.New(…), so a script rescues Spicy::ToolError.
  • The host runs the script with RunContext and passes the same context.Context to the tool call, so a cancelled run reaches a tool that is still working.

Classes from a host

A host cannot define a class. In v0.1.1 the host API defines modules, their methods and their exception classes. It has no way to define a class whose instances a script creates with new and whose methods are Go functions, and no way to keep Go state in an instance.

Two things come close:

  • The script declares the class, with typed fields and methods in amber, and a host method returns instances of it. A proto.Message whose descriptor is a loaded class's becomes an instance of that class.
  • A builtin class in amber's standard library, below, which needs a change to amber itself and is then there for every script and every host.
package main

import (
	"log"
	"os"

	"google.golang.org/protobuf/reflect/protoreflect"
	"google.golang.org/protobuf/types/dynamicpb"

	"github.com/radiospiel/amber/src/amber"
)

const script = `
class User
  string :name
  int :age

  def greeting = "#{name} is #{age}"
end

user = Users.find("ada")
puts user.greeting
p user.with(age: user.age + 1)
`

func main() {
	prog, err := amber.Load("users.arb", script, os.Stdout, os.Stderr)
	if err != nil {
		log.Fatal(err)
	}
	prog.Module("Users").Def("find", func(args []any, kwargs map[string]any) (any, error) {
		// The script declares User; Go builds one from its descriptor.
		desc, err := prog.Descriptor("User")
		if err != nil {
			return nil, err
		}
		user := dynamicpb.NewMessage(desc)
		user.Set(desc.Fields().ByName("name"), protoreflect.ValueOfString(args[0].(string)))
		user.Set(desc.Fields().ByName("age"), protoreflect.ValueOfInt64(36))
		return user, nil
	})
	if err := prog.Run(); err != nil {
		log.Fatal(err)
	}
}
ada is 36
User(name: "ada", age: 37)

Inside amber: a builtin class

amber's builtin classes live in src/stdlib, one file per area. A class is an *object.Class from object.NewClass(name, super):

  • c.Define(name, arity, fn) adds an instance method and c.DefineSingleton(name, arity, fn) a class method, where fn is an object.NativeFn: func(ctx object.Context, self object.Value, args []object.Value, kw *object.Map, block object.Value) (object.Value, error). An arity of -1 takes any number of arguments. ctx raises exceptions (ctx.Raise), calls methods and blocks, and renders values.
  • An instance is an object.Instance with the class and its Fields, as Pathname holds its path.
  • An install… function defines the methods and binds the constant, and stdlib.Install calls it.
  • puts and p render a builtin instance in src/eval/inspect.go, which names each such class: a native to_s or inspect is not enough.

This adds Money, an amount in cents, in src/stdlib/money.go:

package stdlib

import (
	"fmt"

	"github.com/radiospiel/amber/src/object"
)

// MoneyClass is Money: an amount in cents, held as its instance's one field.
var MoneyClass = object.NewClass("Money", object.ObjectClass)

// installMoney defines Money.new(cents), Money#cents, Money#+ and Money#to_s.
func installMoney() {
	c := MoneyClass
	object.ObjectClass.Consts["Money"] = object.ClassValue(c)
	money := func(cents int64) object.Value {
		return object.InstanceValue(&object.Instance{Cls: c, Fields: []object.Value{object.Int(cents)}})
	}
	cents := func(v object.Value) int64 { return v.Instance().Fields[0].Int() }

	c.DefineSingleton("new", 1, func(ctx object.Context, self object.Value, args []object.Value, kw *object.Map, block object.Value) (object.Value, error) {
		n, err := wantInt(ctx, args[0], "")
		if err != nil {
			return object.Value{}, err
		}
		return money(n), nil
	})
	def(c, "cents", 0, func(ctx object.Context, self object.Value, args []object.Value, kw *object.Map, block object.Value) (object.Value, error) {
		return object.Int(cents(self)), nil
	})
	def(c, "+", 1, func(ctx object.Context, self object.Value, args []object.Value, kw *object.Map, block object.Value) (object.Value, error) {
		other, ok := args[0].AsInstance()
		if !ok || other.Cls != c {
			return object.Value{}, ctx.Raise(object.TypeError, "Money can't be added to %s", kindName(args[0]))
		}
		return money(cents(self) + cents(args[0])), nil
	})
	def(c, "to_s", 0, func(ctx object.Context, self object.Value, args []object.Value, kw *object.Map, block object.Value) (object.Value, error) {
		return object.String(MoneyToS(self)), nil
	})
}

// MoneyToS renders a Money as dollars and cents: $14.49.
func MoneyToS(v object.Value) string {
	n := v.Instance().Fields[0].Int()
	return fmt.Sprintf("$%d.%02d", n/100, n%100)
}

A builtin class's instances are not protobuf messages: they cannot be passed to async, which raises "Money is not a class with fields", and they reach a host as an *object.Instance. A new builtin also comes with an example in examples/, whose .expected output go test holds it to, and a line in doc/amber-vs-ruby.md if Ruby has the class too.
