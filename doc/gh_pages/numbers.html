How it was measured:

  • The cases are those of CRuby's own benchmark/ directory that use only what cameo supports, 781 files. A case counts when all three ran it; cameo's output is checked against CRuby's.
  • The machine is a laptop, an Apple M4 with 10 cores, three cases at a time, on 2026-11-13. CRuby is 3.4.1, and "CRuby + YJIT" is the same binary with --yjit. A laptop's times vary more than a server's; read the table for its proportions, not its last digit.
  • A time is the mean of the timed runs of a case after one run to warm up, read from the Ruby's own clock, so no interpreter's start is in it. cameo starts in about 9 ms and CRuby in about 25 ms on this machine.
  • To run it again: ruby benchmarks/compare/compare.rb --rubies mri,yjit,cameo --out benchmarks/compare/yjit.tsv, then ruby benchmarks/compare/categories.rb. yjit.tsv has every case.

cameo is an interpreter without a JIT. Where it spends its time is in benchmarks/compare.

  • The benchmark suite. The 537 cases that do not run are sorted by the first thing that stops each: mutation (119), instance variables (61), attr_* accessors (59), metaprogramming (52) and smaller groups. doc/cameo-vs-ruby.md has the table.
  • ruby/spec, the files. Sorted without running a spec, on 2026-11-13. Most of the rest use an instance variable (1021 files), mostly in mspec's own before blocks, or require a library cameo does not build in (375).
  • ruby/spec, the examples. Run on 2026-11-13. The run of 2026-11-05 passed 1045: since then bytes that are not UTF-8 have to be a binary String, and the 57 examples that stopped passing all stop at that rule. doc/coverage.md says what stops each example that does not pass, and which of those are bugs.
  • The standard library. Ruby 3.4.1 ships 58 default gems and 29 bundled ones. A library goes in when its work is computation on values, and stays out when it is the file system, processes or threads. doc/stdlib.md lists every one with its status.

Against other Rubies inside a Go program

An older run, of 2026-10-19 on a 16-core server, compared cameo with two Rubies that also run inside a Go program: CRuby compiled to WebAssembly, and go-embedded-ruby. Over the cases all four ran, cameo took 2.9 times CRuby's time, the WebAssembly build 7.2 times and go-embedded-ruby 9.9 times. benchmarks/compare has that run.
